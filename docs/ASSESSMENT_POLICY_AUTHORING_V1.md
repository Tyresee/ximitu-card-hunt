# 动态知识点评分与 Codex MCP 创作 v1

- 状态：Implementation Scope
- 日期：2026-07-28
- 首个知识点：`have / has`
- 目标页面：`/teacher/assessment/`

## 用户与任务

教师需要用自然语言或网页表单表达一节课的高权重主考点、常见混淆项、
评分权重和不确定处理方式。Codex 可以通过 MCP 把自然语言转换为结构化草稿，
但不能直接发布、激活或删除线上配置。

孩子作答时，系统必须把“知识点是否正确”和“发音表现如何”分开。主考点错误
不能被整句完整度、流利度或较高的供应商总分抵消。

## v1 工作流

```text
教师自然语言 / 网页表单
  -> 结构化 assessment-policy.v1 草稿
  -> Schema 与语义校验
  -> 正确 / 错误 / 听不清案例模拟
  -> 提交人工审核
  -> owner 在网页确认发布
  -> 新回合读取已发布版本
```

Codex MCP 和教师网页必须调用同一个 Authoring 领域服务。MCP 不模拟点击网页，
不直接写数据库文件，也不接触阿里云密钥。

## 数据模型

每个账号独立保存一份评分策略信封：

- 可编辑草稿及精确 `draftRevision`
- 不可变发布快照及递增 `publishedVersion`
- 内容哈希、校验结果、模拟结果和审核请求
- 创建来源、需求摘要和审计时间

`assessment-policy.v1` 至少包含：

- 主考知识点和显示名称
- `requiredGate`
- 主语到正确形式的映射
- 常见混淆形式
- 错误与不确定处理策略
- 供应商配置档引用
- 知识点正确性、目标词发音、整句发音、流利度四项权重

权重总和必须等于 100。供应商公开能力由只读能力注册表提供；模型不能提交
未登记的原始供应商参数。

## 权限

- 已登录教师可读取能力、查看配置、保存草稿、校验、模拟和提交审核。
- 只有 `owner` 可以在同源网页会话中发布。
- MCP 工具只能读取、保存草稿、校验、模拟和提交审核。
- MCP 不暴露发布、激活、删除或任意脚本工具。
- 所有写入使用精确修订和幂等键；冲突时拒绝覆盖。

## 页面

教师配置页需要显示：

- 自然语言需求摘要
- 高权重主考点规则
- `he/she -> has`、`I/we/they/you -> have`
- 常见错误形式
- 四项权重和总和
- 当前供应商能力及本地补充计算提示
- 草稿、校验、模拟、审核、发布状态
- 正确、错误、听不清三类模拟结果

自然语言摘要不在浏览器中自由解析执行。Codex 或受控服务把它转换为 Schema
允许的字段；网页始终显示可核对的结构化结果。

## 运行时

结果固定分为：

- `correct`：主考点通过，继续计算表现分和骰子等级。
- `wrong`：主考点明确错误，评分动作为 `score_low`，最终分固定为 45；游戏接口
  返回 `accepted` 继续结算，但保留 `primaryAccepted: false`，供应商高总分
  不能抬高。
- `uncertain`：证据不足或互相冲突，进入教师确认。

新策略默认使用 `onWrong: "score_low"`。旧策略中的 `onWrong: "retry"` 仍可
读取和原样保存，不由 normalizer 改写；兼容运行时按同一固定 45 分规则执行。

阿里普通儿童句子结果优先使用 `pron / accuracy`、目标词和音素证据，而不是仅用
`overall`。离散语法题可使用供应商的正确项/错误项能力；能力不可用时由本地
确定性规则和教师确认兜底。

## 验收标准

1. 默认策略为 `have / has`，权重为 `60 / 25 / 10 / 5`。
2. 权重不等于 100、正确形式与混淆项重叠、未知供应商配置档均被拒绝。
3. `She has two apples.` 判为 `correct`。
4. `She have two apples.` 即使供应商 `overall=99` 也判为 `wrong`，最终分
   固定为 45 并继续游戏。
5. 没有可靠转写或目标词证据时判为 `uncertain`，不自动给分。
6. 草稿按账号隔离，修订冲突不会覆盖，幂等重试只产生一次结果。
7. MCP 工具无法发布；owner 网页可发布精确草稿修订。
8. 已发布版本不可原地修改，新课堂回合只读取完整发布快照。
9. 语音流程继续保持“准备 -> 明确录音 -> 手动答完 -> 评分”，不恢复自动提交。
10. 全量单元测试、浏览器 E2E、375px、键盘与 reduced-motion 回归通过。
