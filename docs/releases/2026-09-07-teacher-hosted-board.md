# 老师主持模式发布检查

规则见 [老师主持模式](../TEACHER_HOSTED_BOARD_MODE.md)。父版本：
`6099f888f3c05376f9b282b9787ffc4b52d6ee5f`。

## 范围与验证

- 新开局选择「老师主持 · 自由记分」，沿用学生资料、角色、地图与单局星星规则。
- 老师自由点人奖励单次机会，固定最高阶寻宝骰，不产生任何语音评分/正确次数。
- 新增 8 项用例覆盖 1/2/8 人、同人连续奖励、单次与错误绑定、刷新快照、结束、新局、
  跨世界完整步数、金币/星星幂等以及原语音授权入口。
- 本地完整验证 849 项通过。隔离发布候选 828 项，800 通过、28 个已有失败；
  同时实测生产父版本 820 项，792 通过、28 个已有失败。没有新增失败。
  历史失败涉及未纳入发行的开发美术源文件及旧奖励/投射物断言，不夹带其他脏文件修复。
- 本地 Chromium 实际操作：4 人开局、给第二人机会、刷新恢复、固定寻宝骰、岔路选择、
  仅指定学生移动和入账、同人连续奖励、抽骰后刷新沿用原骰面、停靠锚选择、手动结束。
- 桌面和 375px 检查无横向溢出；老师面板在掷骰动画时收起；暂停和结束文案明确区分。
- 用隔离资料库真实 UUID 学生开新局，初始金币/星星为 0；完成一次老师奖励回合后，
  浏览器与本地服务端均为金币 1、星星 0、语音完成数 0，待同步队列为 0。
- 所有写入测试使用隔离的本地 QA 数据。没有修改真实学生或 Growth 数据。
  浏览器自动化不是实际课堂使用验证，也不是实际手机真机验收。

## 交付方式

从生产父版本建立独立临时索引，只纳入本需求的源代码、文档与相关断言改名。
原工作区 HEAD、正常索引及其余脏改动原样保留，不创建 worktree、不 reset/clean/checkout。
通过项目既有固定部署器进行哈希校验和 release 切换，保留父版本用于回滚。
本模式不改变服务端数据库格式，也不触发原卡片转星迁移。

## 已知边界

游戏进度和未用机会仍保存在当前浏览器，不支持跨设备恢复同一地图；学生每局资产走原有
认证、版本冲突、幂等和服务端事件复算。原知识答题流程继续由真实语音证据决定骰子档位。
