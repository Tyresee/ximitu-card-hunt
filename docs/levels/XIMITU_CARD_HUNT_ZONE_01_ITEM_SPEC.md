## 1. 设计结论

启航海湾的玩家侧身份定为：

> **云港航道调度：用雾笛锁定目标，用云霄大炮快速发射，再开启云瀑航道离港。**

当前保留三个核心地图设施和一个区域结束演出：

| 类型 | 名称 | 节点 | 核心动词 |
|---|---|---:|---|
| 固定地图设施 | 港口雾笛 | `n05b` | 锁定 / 揭示 |
| 固定地图设施 | 云霄信号炮 | `n06a` | 发射 |
| 共享地图设施 | 云瀑水门 | `n12b` | 开启航道 |
| 区域结束演出 | 远航灯塔 | 跨越 `n18 → n19` | 离港 |

这四项分别改变目标状态、棋子位置、地图拓扑和区域环境。`n03` 保留为中性码头节点，
吊机仅作环境装饰，不发道具或替代奖励。

## 2. 不可改变的核心循环

```text
任意知识题
→ 当前答案通过
→ 掷骰子
→ 显示本次路线
→ 按骰点移动
→ 结算最终落点的一个地图设施
→ 进入下一回合
```

知识系统只向棋盘提交“本回合通过”这一结果。地图道具只能读取：

- 当前区域、节点和计划路线；
- 骰子最终点数；
- 当前玩家持有的区域道具；
- 卡匣 / 卡卡精灵等棋盘实体状态；
- 当前 Session 的地图状态和稳定随机种子。

地图道具不得读取：

- 学科、知识点和任务 ID；
- 题目、答案或转写文本；
- 本题属于语法、词汇、数学还是科学；
- 评分档位或具体得分。

验收时，更换任意 LearningPack，只要玩家位置、骰子、路线选择、地图状态和随机种子相同，道具结算就必须完全相同。

## 3. 当前背景与节点适配

启航海湾现有背景已经包含：

- 左侧起航码头和停靠小船；
- 中段云层断谷与高空航线；
- 右侧瀑布、山崖和悬桥；
- 右上角远航灯塔。

因此，道具必须使用独立 SVG / DOM 动态层叠加在背景上，不能把可开关设施直接烘焙进背景图片。

当前区域路线：

```text
n01 → n02 → n03 → n04
                    ├─ n05a → n06a → n07a ─┐
                    └─ n05b → n06b → n07b ─┘
                                             → n08 → n09 → n10
                                                               ├─ n11a → n12a → n13a ─┐
                                                               └─ n11b → n12b → n13b ─┘
                                                                                         → n14
                                                                                           → n15
                                                                                           → n16
                                                                                           → n17
                                                                                           → n18
```

必须保留：

- `n04`、`n10` 作为岔路节点，不放大型设备；
- `n08`、`n14` 作为卡匣 / 卡卡精灵踪迹点，不改成道具源点；
- `n06a → n09` 的现有大炮运输骨架。

## 4. 已取消：停靠锚

- 不再发放、使用、保留选择或归还停靠锚；不显示持有徽章、停靠候选点、询问弹窗和锚的音画演出。
- 骰子落定后仍须完成本次路线上的必要岔路选择，随后按既有骰点走完整路线；没有提前停靠步骤。
- `n03` 的节点和道路几何保持不变，码头吊机只作装饰。经过或最终落在这里不发锚，也不新增替代奖励。
- `n11b` 的原有奖励不变，不转移或补发原锚奖励。
- 旧存档中的 `anchorGrantedBySeat`、`anchorHeldBySeat` 和旧锚结果只兼容读取，不赋予可用道具，不影响新回合的路线和结算。
- 未提交的旧停靠选择不能让恢复后的游戏卡在弹窗中，也不能截短后续提交的骰子路线。
- 已提交回合保持原位置、路线和奖励，不因本次取消而重掷、重走、补走或重新结算。
- 不修改语音评分、骰子档位、骰面快照、随机概率或已抽结果。

## 5. 地图设施一：港口雾笛

### 5.1 定位

| 字段 | 设定 |
|---|---|
| 显示名 | 港口雾笛 |
| 建议 ID | `harbor.foghorn.v1` |
| 固定节点 | `n05b` |
| 触发方式 | 最终停在该节点 |
| 是否持有 | 否，属于地图设施 |

`n05b` 不再轮换金币雨、星星矿脉或与 LearningPack 绑定的课堂 Activity；它固定解析为港口地图效果。

实现时，`n05b` 必须从旧 `eventNodeIds` 和知识 Activity 语义中移除，改为独立的 `mapEffectRef`。

### 5.2 机械效果

有活跃卡卡精灵时：

- 显示精灵所在踪迹点及当前玩家到它的推荐路线；
- 让精灵从触发后持续停留接下来的 `P` 个有效玩家回合，`P` 为当前有效玩家数；
- 不改变棋子点数，也不直接生成卡匣、钥匙或卡片。

没有活跃精灵时：

- 驱散当前视窗局部迷雾；
- 标亮当前玩家前方最近的一个港口设施和一个精灵踪迹点；
- 不强行召唤精灵，不制造额外个人奖励。

无效回答、重试或取消操作不推进停留期限。重复触发时使用
`max(现有到期回合, 当前有效回合数 + P)`，不能把多个雾笛时长相加。

### 5.3 视觉与声音

- 雾笛口产生两至三圈青蓝色声波；
- 声波扫过的区域云雾短暂退开；
- 有精灵时，精灵上方出现“已锁定”航标，精灵做停驻反馈；
- 声音使用儿童友好的低沉“呜——”，不模拟警报或危险警笛；
- 首次动画不超过 `1.2s`，重复动画不超过 `0.8s`。

## 6. 地图设施二：云霄信号炮

### 6.1 定位

| 字段 | 设定 |
|---|---|
| 显示名 | 云霄信号炮 |
| 建议 ID | `harbor.signal-cannon.v1` |
| 固定节点 | `n06a` |
| 运输目标 | `n09` |
| 触发方式 | 最终停在 `n06a` |
| 可用时机 | 开局即可使用 |

它是港口的高空运输 / 信号设施，不攻击玩家、NPC 或其他棋子。

### 6.2 机械效果

- 触发后从 `n06a` 发射至 `n09`，效果等价于额外前进 3 格。
- 首位触发者先轰开航线上的云礁，随后同样完成发射，不承担“只维修、自己不能使用”的成本。
- 后续触发者使用已清理的航线，动画缩短。
- 炮台是从 `n06a` 直达 `n09` 的运输，但公开的飞行捕获路径覆盖 `n08`：
  - 位于 `n08` 的卡匣 / 精灵可以被发现；
  - 棋子不会停在 `n08`，最终仍落在 `n09`；
  - 路线预览必须同时显示“飞行经过 `n08`，落在 `n09`”，不能把捕获路径藏在动画里。
- `n09` 是冷落点：可结算普通个人奖励，但不能继续触发第二个运输或重大地图事件。
- 炮台每回合最多触发一次。
- 运输目标异常时留在 `n06a`，不消耗其他道具，并显示“航线暂时繁忙，本次安全停靠”。

### 6.3 对现有规则的修正

现有“前两个全局有效回合锁定炮台”会固定影响座位靠前的孩子，应取消。

正确规则：

```text
开局可用
→ 首次触发：清除云礁 + 发射当前玩家
→ 后续触发：直接发射，缩短动画
```

### 6.4 视觉与声音

- 炮口朝 `n09` 转向，出现蓝白色蓄力环；
- 首次使用时，一枚软质云弹击散前方云礁；
- 棋子乘坐气泡舱沿抛物线飞行，不把儿童角色塞进炮管；
- 落点产生云朵缓冲垫；
- 声音：`咚 → 咻 → 噗`，避免写实爆炸声；
- 首次动画不超过 `1.3s`，重复动画不超过 `0.8s`。

## 7. 地图设施三：云瀑水门

### 7.1 定位

| 字段 | 设定 |
|---|---|
| 显示名 | 云瀑水门 |
| 建议 ID | `harbor.cloudfall-gate.v1` |
| 固定节点 | `n12b` |
| 触发方式 | 最终停在 `n12b` |
| 共享状态 | `cloudRouteOpen` |

`n12b` 位于现有瀑布下方，适合放置水门转轮和低矮控制台。它不再打开由当前知识任务决定的 Activity。

实现时，`n12b` 必须从旧 `eventNodeIds` 和知识 Activity 语义中移除，改为独立的 `mapEffectRef`；它不是运输节点。

### 7.2 首次机械效果

- 当前玩家转动水门，云瀑改道。
- 水流在 `n14 → n17` 之间生成一条可见的云阶捷径。
- `cloudRouteOpen` 对全班永久开启，直到本次 Session 结束。
- 水门只改变地图拓扑，不额外移动当前棋子；当前玩家已经完成“为全班打开新路线”的共享地图效果。

### 7.3 后续机械效果

水门已经开启后再次停在 `n12b`：

- 只播放缩短版水门与云阶点亮动画；
- 明确显示捷径仍然开放；
- 不重复创建捷径，不重复写入共享状态。

玩家之后从 `n14` 前进且仍有剩余步数时，可选择：

- 常规路线：`n14 → n15 → n16 → n17`；
- 云阶捷径：`n14 → n17`。

两条路线都保持正向可达；水门永远不能关闭唯一主路。

条件边使用稳定定义：

| Edge ID | 路线 | 生效条件 | 顺序 |
|---|---|---|---:|
| `e14` | `n14 → n15` | 始终生效 | 0 |
| `e14c` | `n14 → n17` | `cloudRouteOpen === true` | 1 |

`e14c` 只消耗一个移动步数。路线选择文案使用“云阶捷径”，并明确它会跳过 `n15`、`n16`。如果一次骰程先经过 `n10`、之后又到达 `n14`，路线规划器必须继续询问第二个岔路，不能静默选择默认边；同一次移动需要顺序解析任意多个岔路。

### 7.4 视觉与声音

- 低矮黄铜水门转轮旋转，避免遮挡相邻节点；
- 一束瀑布水流改向，云层逐级凝结成三块发光云阶；
- 已开启状态下，云阶持续轻微发光，成为全班共同改变地图的可见证据；
- 声音：水门机械转动、清亮水流和一声完成钟；
- 首次开路动画不超过 `1.3s`，重复点亮不超过 `0.8s`。

## 8. 区域结束演出：远航灯塔

### 8.1 定位

| 字段 | 设定 |
|---|---|
| 显示名 | 远航灯塔 |
| 建议 ID | `harbor.departure-beacon.v1` |
| 触发位置 | 第一次跨越区域边界 `n18 → n19` |
| 触发范围 | 按玩家记录一次；全班完整演出一次 |

复用背景右上角已经存在的灯塔，不再额外叠放第二座塔或大尺寸文字牌。

### 8.2 效果

- 全班第一位玩家跨越 `n18 → n19` 时：
  - 灯塔点亮；
  - 光束扫向第二区域；
  - 码头旗帜展开、云船解缆、海鸥起飞；
  - 播放一次完整离港转场。
- 后续玩家跨越 `n18 → n19` 时：
  - 只显示短版光束和“已进入风帆高地”反馈；
  - 不重复阻断课堂节奏。
- 不直接发放金币、星星、钥匙或卡片。
- 玩家停在 `n18` 时仍属于启航海湾；只有跨越 `n18 → n19` 才触发离区反馈，不再处理停靠锚。

完整演出不超过 `1.5s`；低动态模式改为灯塔由暗到亮、区域边框高亮和简短文字状态。

## 9. 两个岔路的玩家含义

### 9.1 `n04`：速度还是追踪

| 路线 | 节点 | 含义 |
|---|---|---|
| 炮台快线 | `n05a → n06a → n07a` | 有机会落在炮台并快速飞越；飞行可发现 `n08` 卡匣，但不会停在该节点 |
| 雾笛寻宝线 | `n05b → n06b → n07b` | 有机会锁定精灵，并按常规路线经过 `n08` |

### 9.2 `n10`：即时奖励还是共同开路

| 路线 | 节点 | 含义 |
|---|---|---|
| 星光瞭望线 | `n11a → n12a → n13a` | 保留现有个人奖励机会 |
| 云瀑工务线 | `n11b → n12b → n13b` | 保留普通个人奖励，并有机会开启全班云阶捷径 |

当前界面把 `n10` 写成“风帆高地岔路”，但它仍位于启航海湾，应改名为“云瀑岔路”或“远航信标岔路”。

## 10. 结算顺序与防连锁

单回合统一采用：

```text
1. 答案通过
2. 骰子落定
3. 顺序完成本次骰程中遇到的全部路线选择
4. 提交并持久化本次完整路线与唯一结算 ID
5. 逐格播放移动
6. 处理已提交路线上的一次性经过触发
7. 发现明确经过的卡匣 / 精灵
8. 最多结算一个最终落点地图设施
9. 结算普通个人资产
10. 展示回合总结
```

约束：

- 路线预览、取消选择和动画重放都不能触发离港。
- `n03` 不再拥有发放停靠锚的经过触发；新旧局的后续回合都不产生锚事件。
- 远航灯塔只认已经提交的边界边 `n18 → n19`。
- 单回合最多出现一个运输效果。
- 大炮的目标节点为冷落点；水门不是运输设施，只负责开启共享捷径。
- 冷落点可以结算普通个人奖励，但不继续触发运输或第二个重大地图事件。
- 卡匣 / 精灵只按界面明确展示的实际经过路线判定，不能被隐藏传送吞掉。
- 一次回答、重试、刷新和重连都不能重复开路或重复移动，也不能恢复已取消的锚流程。

## 11. 公平与不惩罚规则

- 地图道具不生成第二套可累计货币。
- 不消耗金币、星星、钥匙、卡盒或卡片。
- 不后退、不减少骰点、不跳过回合。
- 不攻击、推动或偷取其他孩子的棋子和资产。
- 不因设备状态异常阻断主路。
- 区域效果只归属于地图层，不参与知识评分或个人排名。

## 12. 状态与幂等边界

区域状态与个人永久资产分开保存，至少包含：

| 状态 | 作用域 | 幂等要求 |
|---|---|---|
| `anchorGrantedBySeat[seatId]` | 历史兼容 | 只读兼容旧存档，不产生新发放 |
| `anchorHeldBySeat[seatId]` | 历史兼容 | 不显示或激活旧道具，不参与使用、保留选择或离区归还 |
| `cloudReefCleared` | 全班一次 | 只控制炮台首次完整动画 |
| `cloudRouteOpen` | 全班一次 | 重复落在水门不能重复建边 |
| `departureBeaconLit` | 全班一次 | 完整离港演出只播放一次 |
| `regionExitSeenBySeat[seatId]` | 每位玩家一次 | 每位玩家只播放一次短版离区反馈 |
| `foghornHoldThroughTurn` | 全班临时状态 | 重复雾笛只延后到较晚期限，不累加 |

每次大炮运输和地标落点仍使用当前回合唯一结算 ID。状态和棋子位置必须在同一次结算中持久化成功后再播放动画；刷新、重连或重复事件只恢复最终状态，不重复移动或结算。旧锚字段与已提交锚回合仅用于历史兼容，不得重新执行道具效果。

## 13. 首版明确暂缓

以下方案与港口主题相符，但不进入第一版：

| 暂缓内容 | 原因 |
|---|---|
| 云海渡船 | 大炮已经承担直接运输；再加入渡船会让首区出现第二套近似跳跃效果 |
| 吊机横向搬运棋子 | 再增加一次路线选择，容易拖慢第一张教学地图 |
| 全局涨潮 / 退潮循环 | 需要额外状态教学，也容易让不同座位感到机会不一致 |
| 顺风帆 | 与大炮同属额外前进，核心动词重复 |
| 随机补给箱 | 容易退化为“踩格抽奖励”，削弱地图设施的可理解性 |
| 炮弹、燃料、木材等材料 | 会形成第二套经济和额外 HUD |
| 战斗炮击其他玩家 | 破坏课堂友好与个人资产不受损原则 |

后续课堂实测如果显示区域效果密度不足，优先加入“云海渡船”，不同时加入渡船和吊机。

## 14. 实现前验收门槛

实现完成后至少验证：

1. 任意 LearningPack 在相同棋盘输入下得到相同地图效果。
2. 1–8 人都能在离开启航海湾前看到至少一次区域专属效果。
3. 新旧局经过 `n03` 都不发锚；旧局即使持有锚，也不出现停靠询问或截短本次骰程。
4. 大炮首位使用者同样获得发射效果。
5. 水门首次触发只开启 `n14 → n17` 共享捷径，不产生第二次运输。
6. 单回合运输连锁深度始终不超过 1。
7. 所有主路在任何设施状态下保持可达。
8. 地图道具不会减少或转移任何个人永久资产。
9. 重复事件 ID、刷新和重连不会重复开路或移动，不改已提交位置和奖励，不恢复锚流程。
10. 普通动画、低动态模式、键盘操作和移动端都能看清道具名称、路线与最终结果。
11. 现有 `n08`、`n14` 卡匣 / 精灵踪迹点仍然可达。
12. 地图效果相关测试不引用任何具体知识任务 ID。
13. 对 1–8 人及 12 / 15 / 18 / 21 / 24 回合配置，每项至少运行 1000 个稳定种子；覆盖全部骰子档位及 `n04`、`n10`、`n14` 的两侧选择。
14. 岔路与兑换选择仍正常出现；取消锚不会改动骰面快照、已抽骰点或其他地图设施的触发条件。
15. 至少 80% 的标准 Session 在最后一位活跃玩家离区前看到雾笛、大炮、水门三项固定设施中的至少两种；不足时优先调整节点触发方式，不使用与落点无关的隐藏补偿。
