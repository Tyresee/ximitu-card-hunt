## 产品与数据

- [x] 教师可配置 3—8 个结构化词条；多义词可保存明确中文义项。
- [x] 每个怪兽渲染固定 4:3 矩形词图槽，图片绑定词条数据，替换词条无需改游戏代码。
- [x] `apple/banana/book` 的图片、标准音、HP、阈值与波次数据完整，已审核并发布。
- [x] 180 秒完整循环、3—8 个词对应 3—8 路、预备弹、定向伤害、恒速前进、击败、星星、结算均可用。
- [x] 基础/良好/优秀/击败拥有分级本地合成打击声、落点闪光、扩散环、伤害数字，以及对应词图向屏幕中央安全区放大约 2 倍、完整停留约 2 秒、裂开、碎散消失的“灵魂弹出”反馈；不依赖远程音效素材。
- [x] 旧版单包数据首次启动无损迁入素材包库，重复启动不重复建包；服务重启后包列表、包级 `draft` / `published` 和 `activePackId` 均保留。
- [x] 教师可新建、选择、编辑、发布并将已发布包设为当前游戏包；输入不同新词组自动另存，原包不被覆盖。
- [x] 新建克隆包可跨刷新等待第一组词；第一组新词保存或原模板发布后即永久锁定为正式素材包，后续不同词组不会覆盖已生成素材。
- [x] 已生成图片和标准音从 OSS 长期复用；复制或切换素材包不触发不必要的付费生成，也不产生失效的模型临时 URL。
- [x] 游戏只读取显式 `activePackId` 指向的已发布包；发布或保存其他包不会暗中切换当前课堂内容。
