# 额外前进的新落格奖励与特效（2026-11-03）

用户确认：全班前进后，各位实际移动的学生（包括触发者本人）领取自己的新落格积分，并有从新格飞到本人积分栏的动画。
额外前进后的新格除了基础积分，还要继续触发该格的倍率、加成、再前进等特效。单人班同样执行。
当前没有另一个独立的“仅个人前进1”按钮或特效类型；正常单骰1点和一人班前进1都领取实际新落格奖励。

## 查到的缺口

改动前基础积分已逐人结算并含本人，但全班claim后只更新文字/HUD，未接逐人飞币。
旧规则还明确禁止推动落格继续触发特效。本次按用户新决定启用连锁，保留历史快照和重复请求的幂等。

## 结算顺序

1. 原触发回合先领取原落格积分。
2. 老师确认挑战，服务端冻结每人实际移动路径、终点与独立group-landing奖励ID。
3. 浏览器逐步移动、强制保存终点和completedGroupMoveIds后，领取原冻结奖励。
4. 新确认批次带landingEffectsPolicy=group-landing-effects-v1；全部基础奖励到账后，按座位顺序仅一次应用新格特效。
5. 特效保存于award.specialCell、landingEffectsApplied；不伪造成一次真实骰子回合，不新增骰子随机或语音成绩。
6. 现金加成复用原签名bonus接口和稳定ID。失败重试原奖励；同一回执只记一次钱。
7. 下一轮挑战串行处理，必须等上一批基础/特效/加成全部结清；必要挑战结束后才刷新圈次宝藏。

历史无标记的已确认批次只继续原基础奖励，不补触发特效。既有已到账奖励不重算。

## 有限连锁

同格的一次性效果按稳定座位顺序领取；move3先预约，确认才消费，取消不消费。
每课全班前进最多成功3次，达到上限后剩余子挑战exhausted，不继续移动或发新奖励。
再掷保持原不无限连锁规则；多人获得再掷由pendingRerolls队列保存，别人行动不会清掉机会。
双骰仍每人最多持有一次，只在下次服务端原子锁骰时消费。
当前原价500/1000/1500/2500/5000、倍率和固定+100/+50规则保持。

## 飞币与恢复

confirmedGroupCoinGains只提取严格匹配的服务器基础/bonus回执，不从浏览器数值发钱。
每个landing/bonus回执是独立演出组件：基础先到先演出，加成稍后确认只补加成飞币。
钱包确认前只显示待到账；部分到账不会给失败学生假播，也不重播已经成功的学生。

领取前hold各积分栏；播放前同步保留所有计数器，再按相机队列保证每个来源新格可见，金币飞向对应学生的实时积分栏。
多个学生可重叠飞币，普通单人落格的原有动画保持。低动态或缺GSAP时降级数字提示。

独立group-coin-fx-ledger仅保存待演出批次/已开始回执和提示，不授权移动或领取。
丢响应、刷新和重试仍依赖原回合/位置的强制保存证明；可选演出存储失败仅内存兜底，不放宽领取门禁。
旧历史已付回执作为初始基线，不把历史余额当作本次新奖励重播。
