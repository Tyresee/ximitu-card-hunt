# 刷新恢复与重开棋局

2026-11-10：进行中的棋局刷新后自动回到原局，不再要求先在课前页点击“继续本局”。

## 刷新恢复

- 恢复范围是同一浏览器、同一站点的本地存档。它不构成跨设备同步。
- 页面确认当前登录身份、完成配置初始化后，读取未结束且处于 `PLAYING` 的原存档。
  保存的 `ownerUserId` 或旧积分登记的 `landingPoints.ownerId` 必须与当前老师一致；
  未登录、其他账号和布局编辑器入口不自动打开棋局。
- 完整的原学生座位、角色、位置、回合进度和各规则快照仍由现有存档校验与恢复函数读取。
  空闲时老师选中的学生也保存；已有待用机会时，以该机会绑定的学生为准。
- 掷骰机会先强制保存，再向服务端请求锁骰；刷新保留原 `opportunityId / attemptId`。
  已锁骰面、双骰、已冻结路线和待到账事件继续走原恢复链，点击“继续掷骰”只重试原机会，
  不生成另一次机会、重抽已锁骰子或重复领取。
- 已提交的移动直接恢复原最终位置，积分仍须有原提交证明才可领取；未提交的移动按原骰面、
  已保存路线继续完成。演出记录不能替代位置存档或到账授权。
- 损坏、不兼容或无法读取的存档保留原文，不自动清除、覆盖或重开。

## 暂停与结束

主动暂停并返回设置会把存档的 `autoResumeOnReload` 标为 `false`，其学生、位置、机会和
奖励内容均不改变。此时刷新仍留在设置页；点击“继续本局”恢复原存档并重新开启刷新自动恢复。
已结束棋局保留成绩与历史，不自动当作进行中棋局打开。

新元数据均为可选字段，既有 schema 与精确棋盘、骰面、奖励及路线快照不变。旧存档没有
`autoResumeOnReload` 时，未结束的进行中棋局按新要求自动恢复。

## 重开与提示

右下角“⋯”棋局操作菜单提供“重开一局”。确认后沿用结束与封存流程返回学生/角色设置；
取消则继续原局。已到账的家园积分保留，不清空钱包。原掷骰机会、移动、挑战或落格基础与
加成奖励待办尚未结清时不可重开，避免丢失原事务。

老师主持模式移除右侧中间自动消失的“本轮反馈”面板，骰子、走棋与到账仍在原处展示。
失败、待到账和恢复状态继续在操作区显示；知识答题模式仍先展示真实评分。
