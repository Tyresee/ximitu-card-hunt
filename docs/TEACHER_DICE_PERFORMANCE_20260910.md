## 动效设计决策与修改

目的仍是掷出的兴奋感与看清真实结果；保留已有 2000ms、前快后慢的三次缓出轨迹，
不再次通过改转速掩盖渲染问题。WAAPI 只操作 transform，旋转期间临时 will-change；
顶部作为结果，停稳后 2800ms 阅读时间，低动态与取消清理流程保持原样。

| 修改前 | 修改后 | 原因 |
|---|---|---|
| 蒙层底下地图装饰继续无限动画、每帧重绘 | 只在骰子蒙层显示时暂停地图/HUD/候场装饰 CSS 动画 | 本机 trace 确认被遮盖地图仍每帧 Paint |
| 整屏 backdrop-filter: blur(5px) | 不透明度适当增加的普通蒙层，无实时背景模糊 | 减少持续模糊采样与合成负担，保持前景对比 |
| 仅有 rAF 探针，不能代表 GPU 帧率 | 用 DevTools 导出的真实合成轨迹定位完整 cube 动画时间窗 | 不把 JS 回调帧率冒充视觉流畅度 |

动画退出/取消时原 setDiceOverlayActive(false) 恢复装饰；不暂停棋盘规则或 JS 结算。
没有替换 CSS3D 几何、关闭用户硬件加速、伪造骰点或变更其他游戏。
