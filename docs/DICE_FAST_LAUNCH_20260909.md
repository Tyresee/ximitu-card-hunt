# 骰子高速起转与持续减速 · 2026-09-09

用户反馈：目前整个旋转都慢，没有出手很快、随后逐渐减速的实感。这次只调整骰子表现；不改变概率、faceIndex、评分档位、移动、金币、星星或真实学生数据。仍然看最上面的结果面，完整停稳后保留 2800ms。

## 原因与修正

| 原来 | 本次 | 原因 |
| --- | --- | --- |
| 零速起步，到 880ms 才达到峰值 | 出手即峰值，此后连续减速至零 | 上次追求起止平滑，却给开头加入了很长的慢转，不符合最新反馈 |
| 两个轴各约两圈 / 2200ms | X 四圈、Y 三圈，再加结果朝向 / 2000ms | 明显提高真实角速度，两个轴不同圈数形成翻滚 |
| 到达展示位后等待 220ms，再等 160ms 调视角 | 删除静止等待，视角调整与高速起转同时执行 | 避免出手前额外停顿 |
| 抛起曲线到约 943ms 才达顶点 | 500ms 达顶点，随后回落到原位置 | 抛起节奏与快速出手配套；不新增布局、特效资源或物理引擎 |

按 ui-animation 与 3d-build-pitfalls 规范：一次生成 181 个 transform 关键帧，交给 WAAPI；全局 linear 插值，不给每个小段再加缓动。不用主线程逐帧写角度，不改变骰体几何、结果面和最终视角。

新进度为 `1-(1-t)^3`；角速度为 `3(1-t)^2` 乘以总转角/时长。起步速度最大，中间不反转、不重新加速，结尾速度和加速度为零。这是明确设计的抛掷表现曲线，不宣称为刚体碰撞仿真。

### 数值验收（轨迹计算，不是设备帧率）

六种结果下，X 轴各段平均转速：

| 时间 | 转/秒 |
| --- | --- |
| 0–500ms | 4.625–5.203 |
| 500–1000ms | 2.375–2.672 |
| 1000–1500ms | 0.875–0.984 |
| 1500–2000ms | 0.125–0.141 |

以 X=90° 的结果为例，首半秒平均转速从约 0.608 转/秒提高到 4.914 转/秒。所有结果的最后 200ms，单轴剩余转角小于 2°，避免尾段拖着大角度慢转。
