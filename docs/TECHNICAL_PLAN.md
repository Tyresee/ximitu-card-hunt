# 技术方案

## 技术选型

- 前端：语义化 HTML + CSS tokens + 原生 ES Modules；DOM/CSS Grid 与 transform 实现纯 2D 动态 3—8 路舞台，无 Canvas/3D/物理引擎。
- 后端：Node.js 20+ ESM 单进程 HTTP 服务；静态资源、邀请制账号、受保护内容 API、语音评测与备课 AI 代理统一部署。
- 数据：默认种子 JSON 在仓库；账号、邀请码、服务端会话和审计记录写入 `DATA_DIR` 的原子 JSON 数据库；素材按账号目录隔离，全部写入使用串行事务、临时文件 + 原子 rename，部署 release 不覆盖 shared data。
- 测试：`node:test` 覆盖 schema、伤害、状态机、连续词匹配、曲线路径与接口；真实 Chromium 覆盖核心流、异常流和响应式截图。

## 邀请制账号与会话

- 首次启动从仅存在于部署环境的 bootstrap 凭据建立唯一 `owner` 主账号 `[REDACTED_ACCOUNT_PHONE]`；初始化后只保存带独立 salt 和参数的 `scrypt` 密码哈希，不把初始密码写入仓库、前端、日志或持久化明文字段。
- `owner` 创建高熵、单人单次、默认 7 天有效的邀请码；持久层只保存邀请码哈希。注册在同一串行事务中校验并消费邀请码、建立 `member` 和服务端会话，任何一步失败全部回滚。
- 登录使用随机高熵服务端会话令牌，浏览器只接收 `HttpOnly; Secure; SameSite=Lax; Path=/` Cookie，持久层只保存令牌哈希。登录、改密、重置、退出全部设备和账号禁用均可撤销会话。
- 无邮箱/手机号的密码找回由 `owner` 生成 30 分钟单次重置码；重置码同样只保存哈希，使用后撤销该账号其他会话。
- 主账号不能通过管理台为自己签发重置码，只能在账号中心提交当前密码改密；成员主动改密或被停用时，尚未使用的重置码同步失效。
- 匿名请求只允许静态登录/注册页、认证端点和健康检查。所有素材、游戏、生成、上传、评测及 `/ws/asr` 从服务端会话取得 `userId`，不接受前端提交 `ownerUserId`。
- 角色只有 `owner` / `member`。跨账号管理只允许 `owner` 的显式管理 API，并写入不含秘密的审计日志；普通素材 API 永远按当前会话账号解析。

## 账号级素材租户

- 内容层由 `ContentStoreManager` 按认证 `userId` 返回独立 `ContentStore`。每个用户拥有自己的 `pack-library.json`、`packs/`、事务日志和 `activePackId`。
- 为降低上线迁移风险，首次账号化版本把已有根 `DATA_DIR` 以迁移标记绑定给主账号，不移动旧文件、不改写 revision 或 OSS URL；其他账号使用 `DATA_DIR/accounts/<userId>/content/`。
- 所有包 ID 只在当前用户的 store 内解析。读、保存、发布、激活、生成、上传和发音开始前都先验证当前 store 中存在对应包/词条；图片生成互斥键、尝试记录和限流键包含 `userId`。
- 新 OSS 对象使用账号命名空间；读取旧主账号素材时保留 legacy 路径兼容。素材代理校验当前会话是否拥有引用该对象的素材包，避免可逆 token 成为跨账号读取能力。

## 结构化词条与矩形词图槽

- `WordEntry` 是关卡唯一内容源；敌人实例仅引用 `wordId`。
- 怪兽的 `mediaSlot` 为固定 4:3 圆角矩形，图片使用 `object-fit: contain`，背景、描边和安全内边距统一。
- 未审核、缺图或加载失败时显示可读英文占位，不破坏敌人尺寸与道路布局。
- 关卡生成器按 `wave.order`、`repeatTarget` 生成实例，并把排序后的第 N 个词规范化为第 N 路；换内容包无需改动组件。

## 多词语音识别方案

```text
点击开始
  → getUserMedia 取得麦克风
  → AudioWorklet 转 16 kHz / mono / PCM16 / 100ms 分片
  → wss://wordattack.timclass.cn/ws/asr
  → Node 同源代理在服务端附加百炼 Authorization
  → fun-asr-realtime（English + 热词 + 当前词表 context）
  → result-generated final transcript
  → 当前画面白名单精确逐 occurrence 匹配
  → 每词 token bucket（容量 2，每 500ms 补 1）
  → 每个 occurrence 各发一枚 basic(1) 导弹
```

- 前端不持有百炼 API Key。Node 代理仅接受精确同源 `/ws/asr` 升级，每 IP 最多 2 个会话，单分片最多 16 KiB，按 PCM 码率限制总流量，单会话最长 5 分钟。
- 上游使用北京工作空间专属 WebSocket 端点，`run-task` 设置 `language_hints=["en"]`、`max_sentence_silence=450`、`heartbeat=true`、生产热词 ID 与本关词表 context。百炼 `task-started` 前不发音频。
- interim 转写只用于页面反馈；仅 `sentence_end=true` 且精确命中当前词表的 occurrence 发弹。不再将 `look` 自动当成 `BOOK`，避免非目标词误攻击。
- `banana banana` 在同一 final 中产生两个独立命中；同一 `sentence_id` 只结算一次，再用每词容量 2、每 500ms 补 1 的 token bucket 拦截病态重复。
- 百炼实时 ASR 是“词条命中”而非发音评分，单枚固定 1 点伤害；识别置信度不伪装成发音分。
- 不提供 Chrome `SpeechRecognition` 静默降级。麦克风、同源 WebSocket 或百炼上游失败时，游戏保持未开始或停止识别并显示可重试错误。
- 单次建连设 12 秒看门狗，运行中断线有限退避重连；切后台、暂停、播放标准音与结束游戏均关闭本地音频轨与上游会话。
- 播放标准音前暂停识别，音频 `ended` / `error` 后再恢复，避免系统扬声器回灌触发配置词。
- 既有阿里云逐词评测适配器与 `engine.js` 继续保留供历史验证，但主游戏不显示入口、不自动调用，也不参与目标选择或基础弹伤害。
- `MockPronunciationAdapter` 只在非生产环境接受 QA 档位并返回确定性分数；生产关闭 mock 路由和任意客户端分数。
- 服务端使用 AppSecret 换取默认 7200 秒 `warrant_id`，浏览器只收到 AppID、匿名 userId 与临时 warrant；长期 Secret 永不下发。
- 评测固定 `coreType=en.word_kid.score`，已知单词写入 `refText`，`accent` 映射英式 `en` / 美式 `am`，关闭音频 URL 返回。
- 伤害唯一读取 `result.pron`；`overall`、音量和单词细分分数不参与伤害。空 `result`、漏读 `dp_type=1`、严重 `tipId` 或超时均作为柔和重试。

## 发射与曲线弹道

- 当前词包的 3—8 只存活怪兽全部可见，并在各自道路上并发推进；语音匹配只切换本次攻击锁定，不会让其余道路进入等待或变暗。目标弹道在途期间仅暂停该目标的位移，避免命中锚点漂移，其他道路继续推进。
- 敌人逻辑进度统一为 `0..100`。每次渲染或战场尺寸变化时，用 `ResizeObserver` 读取怪兽无位移出生点、机器人实际右边缘和 8px 安全间距，得到当前跑道像素长度；CSS 只用 `transform` 把百分比映射为真实位移。100% 的存活敌人触发 `line_breached`，先显示破线反馈，再写入失败结算。不同视口只改变像素路程，不改变到达所需时间。
- 发射器和每个怪兽分别提供稳定的炮口锚点与目标锚点。发弹瞬间使用 `getBoundingClientRect()` 读取两点在战场容器内的真实中心坐标，不使用固定百分比或仅靠 `vw` 推算。
- 每枚导弹拥有唯一 ID、独立 DOM 节点、SVG 曲线路径和 Web Animations 飞行动画。路径从炮口点开始，经上扬控制点弯向对应怪兽，路径本身可见，因此同时具备“从起点发射”和“有弹道”的视觉证据。
- 飞行控制器允许多枚在途。final 结果的多个 occurrence 逐个排队起飞，但不等待上一枚命中；状态重绘时先临时保留在途节点再重新挂载，避免全量 DOM 更新造成瞬移或动画中断。
- 命中按导弹所属 `entryId` 读取最新敌人状态并原子结算。敌人被击败后只掉落一次星星；后到导弹不得重复扣血或重复计奖。
- 内容校验要求按 `wave.order` 排序后的 `enemy.lane` 严格为 `0..N-1`。读取旧版三路循环数据时先自动规范化；为保证紧急回滚仍可读取，持久化文件继续写成旧版 `lane % 3` 形式，而当前 API 与运行时始终返回动态道路。若弹道锚点缺失或动画创建失败，本次攻击不得扣血。
- `prefers-reduced-motion` 下缩短飞行时间并降低附加特效，但仍保留从炮口到目标的明确空间因果。

## 长期多素材包库

- `DATA_DIR` 下维护素材包注册表和按稳定 `packId` 隔离的文件；注册表只保存包索引、更新时间与唯一 `activePackId`，每包分别持久化 `draft` 和 `published`。
- 新建克隆包在注册表中保存单向 `awaitingFirstWordGroup` 与初始词序签名：普通参数保存不清除；首次不同词序保存或任意发布会永久清除，防止已生成但未发布的付费素材被下一组词覆盖。
- 初始化以幂等迁移读取旧版 `published-pack.json` / `draft-pack.json`：按原 `id` 写入素材包库，保留内容、修订号和当前发布包；迁移中断后重启不得重复建包或丢失旧文件。
- 所有写入继续使用临时文件 + 原子 rename。保存、发布和激活先写不可覆盖的原子事务日志；进程中断后先恢复或安全前滚，恢复失败立即停止全部写操作，公开读取等待事务结束，不暴露未提交内容。
- 乐观并发校验以单个包的 `revision` 为边界：同包过期修订返回冲突，不同包可独立保存；发布只清理该包草稿，不影响其他包。
- 教师 API 提供素材包列表、新建或复制、按 ID 读取/保存/发布，以及“设为当前游戏包”。只有已发布包可写入 `activePackId`；公开游戏接口不接受隐式“最后编辑包”，只解析该指针并返回对应发布版。
- 批量生成前比较规范化词组；词组变化时先建立新 `packId` 再写入生成结果，避免覆盖当前包。相同词条优先复制既有持久化素材引用，只有缺失或明确重新生成时才调用付费适配器。
- 教师端记住最后编辑包和未提交的词组输入；切包、进入游戏及 SPA 后退前先保存脏草稿，生成或保存进行中拒绝离页。冲突时保留本地修改并提供显式放弃后重新载入，超时后以服务端内容对账但绝不把“事务待恢复”误判为成功。
- OSS 对象继续位于 `packs/<packId>/words/<slug>/...`。素材包元数据只保存持久化 URL，服务重启、版本发布和切换当前包都不移动或删除已生成素材。

## AI 内容适配

- `ImageGeneratorRouter`：按环境配置从火山方舟 Seedream、智谱 CogView 和北京百炼中选择可用服务；未配置新密钥时保持现有百炼链路。只在明确可重试、尚未取得图片的 429/5xx 等故障上跨服务降级，内容审核拒绝、超时或可能已计费时不重复调用。
- `ImageGenerationAdapter`：三家共用简洁、正向的儿童 2D 配图提示，每次只生成 1 张 4:3 图片；百炼内部仍以 `wan2.7-image-pro` 为主、`qwen-image-2.0` 为备用。
- `TtsAdapter`：北京百炼 `cosyvoice-v3-flash`；美音默认 `loongannie_v3`，英音默认 `loongemily_v3`，生成统一标准读音。
- `ImageQualityGate`：服务端严格解码或从固定官方主机下载图片，先做文件签名与空白/近纯色检测，再把同一份图片字节交给 `qwen3.6-flash` 核对词义；不合格结果不写 OSS、不覆盖草稿，并自动重试一次。
- `AssetStore`：只把通过质量门禁的素材写入私有 OSS 前缀 `voice-word-attack/<environment>/packs/<packId>/words/<slug>/...`；签名下载或同源代理读取，不长期使用模型临时 URL。
- 所有适配器提供 `health/configured` 状态，不返回任何密钥或完整上游错误体。

## 安全与隐私

- 教师页、游戏页、内容编辑 API、付费 AI/语音接口和实时 ASR 全部要求有效账号会话；同源校验只作为 CSRF 防线，不能替代认证与归属校验。
- API 设置请求体上限、目标词白名单、公开认证端点的 IP 总限流与账号组合限流、改密账号限流、全局图片并发队列、账号级同词生成互斥、安全头与去标识化请求编号日志；仅尚未取得任何上游图片的失败会退回本地额度。
- `Permissions-Policy` 只向同源开放 `microphone`。麦克风音频以内存中 PCM 分片经项目服务器代理流式发往百炼，不写项目磁盘或 OSS。
- `/ws/asr` 在 upgrade 完成前二次复验会话；停用、重置、退出全部设备或改密撤销会话时，服务主动关闭对应的既有语音连接。账号私有素材代理使用 `private, no-store`，退出或换号后不能复用旧缓存。
- 日志只记录精简上游错误码，不记录音频、完整上游响应、API Key 或热词 ID。
- AI/RAM/OSS 使用独立最小权限身份与前缀；`.env` 与密钥永不提交。

## 可测试性

- `?qa=1` 仅在本地/测试环境启用，提供确定性按钮触发录音中、预备弹、各伤害档、击败与结算状态。
- QA 提供确定性的 `APPLE 单发`、`BOOK 单发`、`BANANA ×2` 与按当前词数生成的 N 路齐射入口；单元测试另覆盖 3—8 路渲染/命中、百炼 run/finish 协议、专属端点、热词/上下文、final 精确命中、未知词忽略与重复 `sentence_id` 去重。
- 素材包测试覆盖旧数据幂等迁移、重启持久化、跨包草稿/发布隔离、`activePackId` 切换、同包修订冲突、不同包并发保存，以及 390×844 教师端新建/选择/发布/设为当前包。
- 生产构建忽略 QA 查询参数，且 mock 分数控制端点关闭。
- 每个关键 DOM 状态提供稳定 `data-testid` 和 `data-state`，便于浏览器断言与截图。

## 成本边界

- 持续识词接入百炼 `fun-asr-realtime`，使用现有北京工作空间 API Key 与项目专用热词表，按服务实际可计费时长产生费用。
- 麦克风暂停、页面隐藏、标准音播放和游戏结束均立即关闭实时会话，避免无效时长计费。
- 阿里云 SSECP 仅保留为未进入主游戏的既有适配器；图片与 TTS 不重复生成。项目累计费用上限继续锁定 2 元。
