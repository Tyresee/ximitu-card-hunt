# 等价路线自动前进

2026-11-10：两条路的本次结果一样时，不再打开岔路按钮或选路弹窗，直接沿第一条合法路线继续逐格前进。

用户进一步确认：必须最后汇合到同一格才自动。比较最终落格、已锁定的基础积分与当前生效的落格特效；
只是同分同效果但停在不同格时仍由老师选择。倍率、固定加成、红包、全班前进、再掷及双骰等效果
不同也保留选择。已消耗的特效按普通格比较。

比较同时保留地图状态、经过效果、运输、终点/完圈和跨世界剩余步数的差异。尚有后续岔路时比较
全部合法结果集合：前面已汇合且不影响后续结果的岔路可以省略，后面的真实差异仍需选择。
未知规则或搜索无法完成时保留原选择，不根据默认预览假定两路相同。

自动选择仍生成明确的 `junctionNodeId → edgeId`，沿用原机会、保存、服务端路线核验、逐格移动、
最终停格与到账流程。服务端不接受省略实际经过的岔路，不信任本地计算的奖励。已冻结的旧路线保持原样。
固定采用合法边的稳定顺序，刷新不另抽随机数、不重掷骰子。

骰点用完即停在本次终点，即使终点本身是岔口也不再询问下一步。云港 n49 仍在到达时完成一圈；
正好用完步数则停在 n49，下一次行动才零步经过 n01 并走到 n02。到终点不新增确认或选路动作。
