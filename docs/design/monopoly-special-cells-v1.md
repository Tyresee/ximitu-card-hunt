## 0. 一句话玩法

**每节课开局，棋盘上随机「掉落」一批特效格：停在倍率格，这一格的积分翻倍；停在全班格，老师随口布置一个小挑战，全班做到、老师点确认后，全班一起往前走。**

### 1.3 明确不做

- **惩罚格**（后退、扣分、停一回合）：不做。「原地休息一下」也不做——课堂上它只会制造失落，不帮控场。
- **传送门**（跳到下一个特效格）：不做。投屏上看不清终点、容易连环触发、和弹床/滑梯抢「运输」概念。
- **×1.2**：不做。投屏上 100→120 感受不到；用「幸运袋 +100」代替低档加成，更好懂。
- **任务模板**：全班格只显示「老师有一个小挑战！」，任务由老师随口说（坐好、安静 10 秒、看老师、做完这页……），系统不规定教法。

## 2. 每节课随机掉落规则

### 2.1 数量（按人数 × 老师档位）

人少时总停格次数少，需要更多特效格才能碰到。

| 人数 | 少 | **中（默认）** | 多 |
|---|---|---|---|
| 1–2 人 | 8 | **12** | 16 |
| 3–5 人 | 6 | **10** | 14 |
| 6–8 人 | 5 | **8** | 12 |

参考估算：4 人 × 约 8 回合 ≈ 32 次停格；10 个特效格约占可落格的 8–9%，一节课大约碰到 **2–4 次**。

### 2.2 稀有度权重（每个格独立抽类型）

| 类型 | 权重 | 本局上限 |
|---|---|---|
| 闪亮星 ×1.5 | 25% | — |
| 全班前进 1 | 18% | — |
| 幸运袋 +100 | 15% | — |
| 双星 ×2 | 15% | 3 |
| 全班前进 2 | 8% | 2 |
| 全班小红包 | 8% | 1 |
| 再掷一次 | 5% | 2 |
| 金皇冠 ×3 | 4% | **1** |
| 全班前进 3 | 2% | **1** |
| **合计** | **100%** | 移动类（6–8）合计 ≤ 4 格 |

抽中的类型已达上限 → 在剩余类型里按权重重抽。

### 2.3 摆放约束

1. **禁放格**：起点、起点后前 3 格；运输源 `n06a`、`n12b`；冷落点 `n09`、`n14`；灯塔 `n18`；分岔决策格；地图上其它设施格。
   - 结果：运输落点永远不会是特效格，运输和特效不会叠在一起。
2. **最小间距**：任意两个特效格沿路线 ≥ 4 格。
3. **分散**：按两个世界的格数比例分配；特效格数 ≥ 4 时，晶港四区每区至少 1 个。
4. **高档限制**：金皇冠 ×3 只能放在 100/200/300 格；双星 ×2 不限。
5. **全班前进 3** 不放在两个世界的最后 10 格（避免一推冲到终点）。

### 2.4 种子与公平

- 开局由**服务端**生成种子：`layoutSeed = hash(sessionId, drawNumber)`，按种子确定生成布局。
- 布局（格 ID → 类型）+ 种子 + `drawNumber` 写进本局**规则快照**；刷新、重连、回放结果完全一致。
- 浏览器只负责展示，不参与抽取。

### 2.5 开局掉落演出

- 时机：老师选完学生名单、即将进入地图时；第一次掷骰之前。
- 顺序：**先亮出「本节课宝藏」阵容 → 再化作流星撒到地图上**。总时长 6–9 秒，可一键跳过；重新掉落播 3 秒短版。
- 详细分镜见 **§5.1 开场掉落特效分镜**。

### 2.6 老师操作

- **重新掉落**：第一次掷骰前不限次数；每按一次 `drawNumber+1`，换新种子。第一次掷骰后布局锁定。
- **锁定喜欢的格（可选，P1）**：重掉前点某个特效格加锁（最多 3 个），重掉时锁定格保留，其余重抽；锁定格仍计入数量和上限。

## 3. 倍率结算规则

1. **只认最终停稳格**：完整路线（含弹床/滑梯运输）**真正停下的那一格**是倍率格才生效；路过不算。运输落点是冷落点，不会有倍率，所以「被弹到倍率格」不会发生。
2. **计算**：`金额 = round10(基础档 × 倍率)` 或 `基础档 + 100`；四舍五入到 10。
3. **单笔上限**：3000。
4. **不叠加**：一格只有一种类型；一次停格只结算一种效果。
5. **一次性格**（已拍板 2026-10-19）：所有积分类格（闪亮星、幸运袋、双星、金皇冠、全班小红包）以及全班前进 3 触发后熄灭成普通格（快照记录状态，不会重复触发）。全班前进 1/2 与再掷一次整节课有效。
6. **服务端权威**：claim 时服务端用规则快照里的布局和格状态算金额；**浏览器不传金额**；幂等键沿用现有 claim 键（每次停格一笔）。
7. **全班小红包**：触发者的本格 claim 照常；另由服务端为在场每位学生各发一笔 +50，幂等键 `instanceId + studentId`。全班前进后的逐人新落格原格价属于另一项用户明确授权的奖励，见下节。

### 结算示例

| 基础档 | 闪亮星 ×1.5 | 幸运袋 +100 | 双星 ×2 | 金皇冠 ×3 |
|---|---|---|---|---|
| 100 | 150 | 200 | 200 | 300 |
| 200 | 300 | 300 | 400 | 600 |
| 300 | 450 | 400 | 600 | 900 |
| 500 | 750 | 600 | 1000 | —（不放） |
| 1000 | 1500 | 1100 | 2000 | —（不放） |

投屏写法：`200 × 2 = 400！`，直接展示算式，孩子看得懂、也能顺便做口算。

## 4. 全班移动结算

1. **流程**：学生停在全班格 → 照常领本格积分 → 投屏「老师有一个小挑战！」→ 老师口头说任务 → 老师点 **完成**（全班前进 N）或 **取消**（不移动，格子保留）。没有超时自动发放。
2. **谁移动**：**全班都走，包括触发者**（已拍板）。
3. **逐人领取新落格**：服务端先冻结位置与每人独立奖励 ID；棋子停稳且浏览器保存终态后，每位实际移动学生领取自己新格的原格价，进入原家园钱包。触发者先领原骰程落点，再领推动后新格，两笔身份独立。
4. **不连锁**：推动只按新格基础价到账，不触发特效格加成、运输或新挑战。分岔走地图默认主路线；新圈制从 `n49` 下一步到 `n02`，旧远征路线仍按原快照处理，若停在末端而没有实际移动则不造新奖励。
5. **之后**：全班新落格全部到账后，下一次从新位置正常掷骰；正常停格时，特效格照常生效。全员完圈的 bonus 刷新也等本次推动到账完成。
6. **每节课上限**：全班移动成功发放 **≤ 3 次**；达到上限后剩余全班格变灰，显示「今天走够啦」，当普通格处理。
7. **幂等**：`moveInstanceId` 一次确认只生效一次；每个学生的落格 ID 独立且稳定。断网或部分到账时只重试未成功回执，不重算路线、不重复推动或发奖；历史已确认但没有奖励事件的推动不追溯补发。

## 5. 投屏呈现

| 类型 | 颜色 | 落地特效 | 大字 |
|---|---|---|---|
| 闪亮星 / 双星 / 金皇冠 | 金黄（皇冠更亮带光芒） | 星星爆开 + 数字翻滚 | 「200 × 2 = 400！」 |
| 幸运袋 | 暖橙 | 布袋弹开掉金币 | 「+100！」 |
| 全班小红包 | 红 | 红包雨飘向所有棋子 | 「全班每人 +50！」 |
| 全班前进 1/2/3 | 薄荷绿 | 脚印光带铺向全班 | 「老师有一个小挑战！」→「全班前进 2！」 |
| 再掷一次 | 天蓝 | 骰子闪光弹跳 | 「再掷一次！」 |

- 图标 ≥ 格宽 60%，1920×1080 下后排可辨认；文字 ≥ 28px 等效。
- 低动态模式只淡入加大字，算式和结果照样显示。

### 5.1 开场掉落特效分镜

**时机**：老师选完学生名单，点「进入地图」之后；第一次掷骰之前。  
**顺序**：先亮出「本节课宝藏」阵容 → 再把宝藏化作流星撒到地图上 → 准备开始。  
**总时长**：完整版 **6–9 秒**（随特效格数量自动压缩）；重新掉落播 **3 秒短版**；随时可一键跳过。  
**原则**：布局由服务端按种子抽好（`draw` 返回后才开播）；动画**只负责演出，从不决定位置**。

#### 时间线（以 10 个特效格、5 种类型为例，约 8.4 秒）

| 拍 | 时间 | 画面 | 声音建议 |
|---|---|---|---|
| **Beat 0 · 转场** | 0.0–0.8s | 名单卡片向上淡出；镜头从角色区拉远成晶港**全图俯瞰**（两个世界都入画，只用现有地图美术，不新增画风）；地图压暗到约 55% 亮度，四角淡蓝暗角。动物棋子已就位在起点。 | 轻柔「呼——」风声 |
| **Beat 1 · 宝藏亮相** | 0.8–3.8s | 画面中央升起**星门宝箱**（贝壳纹木箱 + 薄荷云絮，与弹床底座同一造型语言），0.5s 开盖、喷出光柱；标题大字 **「本节课宝藏」**。宝藏卡从光柱里飞出，在箱子上方排成一排，**按类型分组逐张翻面**（每组 0.18–0.3s，组越多越快）：先普通（闪亮星、幸运袋、全班前进 1），再少见（双星、全班前进 2、小红包、再掷），最后稀有。每张卡右上角显示数量徽章 **「×3」**。**稀有卡（金皇冠、全班前进 3）**多给 0.6s：卡面金色闪光、整排卡片轻微后仰、徽章变金边，副字「稀有！」。 | 开箱「吱呀 + 叮」；翻卡「嗒」声音高逐张上升；稀有卡「锵——」+ 闪光 |
| **Beat 2 · 流星撒格** | 3.8–7.3s | 卡片依次化作**带拖尾的发光流星**（颜色沿用 §5：金黄 / 暖橙 / 红 / 薄荷绿 / 天蓝），沿抛物线弧飞向各自的格子。每颗流星飞行 0.7s，相邻两颗相隔 0.15s 起飞（越多越密）。落地：圆环光波 2 圈 + 8–12 粒火花，格上图标「啵」地弹出并轻微回弹。**稀有最后落**：前面全落完后停 0.2s，稀有流星慢动作飞入（飞行 1.0s；有 2 颗稀有时同时飞），落地金色大光环 + 轻微镜头震动（4px，150ms）。 | 每颗「咻——」+ 落地「叮」（倍率类偏高音，移动类偏低音）；稀有落地「咚！」+ 闪光 |
| **Beat 3 · 收束** | 7.3–8.4s | 地图亮度恢复，所有特效格图标常驻在格上；空了的阵容排缩小飞到右上角，变成**可折叠图例**（图标 + 数量）；宝箱合盖淡出。中央大字 **「准备开始！」**，停留 0.8s 后缩小。掷骰按钮亮起。 | 一个明亮的大三和弦 |

#### 时长自动压缩

- 翻卡每组 `flip = clamp(1.5s / 类型组数, 0.18s, 0.3s)`；类型最多 9 组。
- 流星间隔 `stagger = clamp(2.4s / 格数, 0.08s, 0.2s)`；普通流星飞行 0.7s，稀有固定 1.0s。
- 校核：16 格 / 9 组 / 2 稀有 ≈ 0.8 + 3.0 + 3.9 + 1.1 = **8.8s**；5 格 / 3 组 ≈ **6s**。任何情况都必须 ≤ 9s，超出时先压 stagger 再压翻卡。

#### 跳过与重新掉落

- **跳过**：点画面任意位置、按空格或右下角「跳过 ⏭」→ 立即停掉时间线，所有图标直接出现在格上，图例收到角落，显示「准备开始！」0.5s。
- **重新掉落**（第一次掷骰前）：先调用服务端 `draw`（`drawNumber+1`），返回后播 **3 秒短版**：旧图标 0.3s 碎成星屑飘走 → 阵容 0.8s 一次性弹出（不逐张翻，稀有仍闪金）→ 流星撒格 1.5s（无慢动作、无震动）→ 收束 0.4s。
- 布局接口慢：显示「宝藏准备中…」（宝箱轻轻抖动），最多等 3s；失败则提示「再试一次」按钮，**绝不用前端临时编一个布局**。

#### 低动态模式（`prefers-reduced-motion` 或老师「简化动画」）

- 不拉镜头、不飞流星、不震动、不粒子。
- 阵容卡一次性淡入 0.4s（稀有卡静态金边）→ 停留 0.6s → 所有格上图标同时淡入 0.4s，稀有格静态金色描边 → 「准备开始！」。总长 ≤ 1.5s。
- 结果信息不少：阵容、数量、格上图标照常显示。

#### 投屏可读（1920×1080）

- 标题「本节课宝藏」≥ 64px；阵容卡 ≥ 160×200px，类型名 ≥ 28px，数量徽章 ≥ 36px 粗体；「准备开始！」≥ 72px。
- 阵容排一行最多 9 张，居中，不压到地图上的格子标签；流星拖尾不穿过标题区。
- 压暗只用于 Beat 0–2，地图在压暗时仍可认出（不全黑）。
- 格上最终图标 ≥ 格宽 60%（同 §5）。

#### 刷新与一致性

- 演出是纯前端、可丢弃的：中途刷新 / 重连 → **直接显示最终布局**，不重播（本地 `introSeen[sessionId:drawNumber]` 标记）。
- 演出顺序由布局决定：先按类型组（普通 → 少见 → 稀有），组内按格子在路线上的序号；同一 `sessionId + drawNumber` 每次播都一样。
- 演出没结束前不能掷骰；跳过等同结束。

#### 给 Codex 的技术提示

- 独立模块 `SpecialCellsIntroSequencer`：输入为快照布局 + 每个格子的屏幕坐标（来自现有 Board 渲染）；`play({ mode: 'full' | 'short' | 'reduced' }) → Promise`；`skip()` 让 Promise 立即 resolve。
- 叠加层（overlay）位于棋盘之上、HUD 之下；不往文档流插节点，**不引起布局偏移**。
- 卡片用 CSS transform/opacity；流星、拖尾、粒子用一个 Canvas 2D（或项目已有动效引擎），`requestAnimationFrame` 统一时间线。
- 开播前预加载并 `decode()` 所有图标和卡面；粒子总数 ≤ 300。
- 交接：格上真实图标由棋盘层渲染，在对应流星落地前只是 `visibility: hidden`，落地瞬间显示（不移动 DOM）。
- 目标 60fps（教室笔记本 + 投影）；连续 10 帧 > 24ms 时自动减半粒子、关拖尾。
- 声音沿用现有音效通道与静音开关，音量偏柔；没有音效资源时静默，不阻塞演出。

#### 验收

1. 选完名单进入地图：依次出现转场 → 宝藏阵容（分组翻牌 + 数量徽章 + 稀有金闪）→ 流星撒格（稀有最后、慢动作）→「准备开始！」；10 格完整版 6–9s，16 格 ≤ 9s。
2. 阵容的类型和数量与服务端快照完全一致；每颗流星落点等于快照里的格子。
3. 跳过：任意时刻点击 → 1 帧内显示最终布局，可掷骰。
4. 重新掉落：短版 ≈ 3s，新布局与新 `drawNumber` 快照一致；第一次掷骰后按钮消失。
5. 演出中途刷新 → 直接最终布局，不重播，不重抽。
6. 低动态：无位移/粒子/震动，≤ 1.5s，信息完整。
7. 1920×1080 投屏截图：标题、徽章、格上图标后排可辨认。
8. 教室级笔记本 Chrome 性能面板：演出期间平均 ≥ 55fps，无布局偏移（CLS = 0）。
9. 布局接口失败时不出现任何前端编造的特效格。

## 7. 给 Codex 的 P0 开工说明

**目标**：新局可以随机掉落 9 种特效格，倍率由服务端结算，全班移动经老师确认。旧局不受影响。

**服务端改动**
1. 新规则版本：`RewardPolicy = points-only-v2-special-cells`。新局才启用，旧局快照不迁移。
2. 布局生成：`POST session/:id/special-cells/draw`，仅在第一次掷骰前可调用；按种子执行 §2 的数量、权重、上限、约束；结果写进规则快照（`layoutSeed`、`drawNumber`、`cells[]`、`consumed[]`）。第一次掷骰时锁定。
3. claim 计算：读取快照，对最终停稳格应用倍率或 +100；round10；上限 3000；一次性格标记 consumed。仍沿用现有幂等键，不接受客户端金额。
4. 全班小红包：同一事务内为在场学生生成 +50 claim，幂等键 `instanceId+studentId`。（已拍板保留。）
5. 全班移动：`POST …/group-move/:instanceId/resolve {confirm|cancel}`；按权威图推进 N 步（默认分支、不触发特效或运输、不 claim）；每局成功次数上限 3；幂等。
6. 再掷一次：本格 claim 完成后，给触发者发一次额外的合法骰；第二次停格如果又是「再掷」，不再追加。

**前端改动**：开场掉落分镜（§5.1：宝藏阵容 → 流星撒格 → 准备开始，6–9s 可跳过，重掉 3s 短版）+ 重新掉落按钮 + 数量档位；特效格常驻图标；落地大字和算式；全班格弹出「完成 / 取消」两个按钮；角落图例。

**验收**
- 同一 `sessionId + drawNumber` 两次生成的布局完全一致；重新掉落会换布局；掷骰后无法重新掉落。
- 1000 次模拟生成：不违反禁放格、间距、分散、上限（×3 ≤ 1、全班前进 3 ≤ 1、移动类 ≤ 4）。
- 停双星 200 格 → 钱包 +400 一笔；路过不加；刷新或重试不会多发。
- 弹床/滑梯运输后，按落点（冷落点）原价结算，不出现倍率。
- 全班前进：取消不移动；确认只推一次；被推的人不入账、不触发连锁；第 4 次显示「今天走够啦」。
- 关闭倍率类后，布局里不出现类型 1–5。
- 开场分镜满足 §5.1 验收。
- 旧局行为、Board 坐标、运输规则不变；`npm run verify` 全绿。
