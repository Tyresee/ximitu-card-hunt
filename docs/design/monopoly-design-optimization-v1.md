## 0. 设计目标（可验收）

1. **路上有「看得见的好玩」**：除最终停格 100/200/300/500/1000 家园积分外，每局平均至少出现 **2–4 次** 过程惊喜（运输演出 / 局内道具 / 全班小高潮），且学生能用一句话说出「刚才发生了什么」。
2. **设施可教、可投屏**：云朵弹床、彩虹滑梯在静止态就能读出功能；触发时有固定五阶段演出（进入→途中→离开→落地→文案），投屏 1920×1080 下角色与设施接触点清晰，低动态模式仍有可读落地结果。
3. **底座不「怪」**：弹床/滑梯底座改为与晶港草地、云海、贝壳屋一致的造型语言；去掉「未知石块」观感，背景建筑与棋盘设施层次分明。
4. **积分链路不破**：平台钱包仍只在「完整路线真实最终停稳格」入账一次；过程奖励默认进 **局内临时层**，不自动写入家园钱包；老师可开关/裁定，不绕过服务端锁骰与幂等 claim。
5. **分层可交付**：Codex 可按 P0（可读性）→ P1（过程奖励）→ P2（更深节奏）落地，每阶段有独立验收标准，不强迫一次做完经济系统。

## 1. 问题诊断（对照用户反馈 + 现状文档）

| # | 用户痛点（精神忠实） | 现状（文档/实现） | 根因判断 |
|---|---|---|---|
| 1 | 除积分外，路上应有更有趣的奖励，不能只有扁平积分 | `POINTS_ONLY_REWARDS.md`：骰子只决步数；旧币/星/骰面附加奖已退役；仅最终停格家园积分 | 经济收敛正确，但 **过程层被一并抽空**；运输（弹床/滑梯）有位移却没有「奖励感」叙事 |
| 2 | 云朵弹床看不懂：像装饰，不知道干什么、触发什么特效 | `PLAYGROUND_FACILITIES_V2`：`n06a` 停稳才运输到 `n09`；路过不触发；插画层已换薄荷弹面（`ILLUSTRATED_FACILITIES_V1`） | **规则存在、可读性不足**：静止态无「弹一下就飞」的符号；触发时文案/HUD 未把「跳到前方」说透；学生以为只是地景 |
| 3 | 弹床下石块奇怪/未知；设施整体装饰感强、玩法感弱 | 插画去掉机械（吊机/炮/水门塔），改 2.5D 云垫；底座仍可能呈硬质方块或与地形脱节 | **造型语言断裂**：云软 + 硬石底座冲突；缺少「可玩设施」的交互暗示（箭头、落点光环、气泡） |
| 4 | 希望整局有强力整体设计优化 | 主循环稳：老师点人→掷骰→逐格→运输→最终格积分；节奏偏「走格子领钱」 | 缺 **开局/中盘/终局高潮点** 设计；设施与奖励未形成「晶港游乐场」一体体验 |

**不改的边界（已批准契约）**

- 最终停格平台积分档位与 claim 链路保持。
- 老师主持自由记分为默认；1–8 人；动物角色；晶港四区图。
- 路过不触发运输；冷落点（n09/n14 等）不连环二次运输。
- 旧局精确版本快照不静默迁移。

## 2. 核心原则（课堂可教、投屏可读、老师可控、积分链路不破）

1. **一句话能教**：每个设施/过程奖励，老师用 ≤8 个汉字或一句英文课堂话术就能讲清（例：「停在云上，弹到前面！」）。
2. **静止态可读，动态态庆祝**：没触发时也能看懂「这是什么」；触发时用大字气泡 + 固定 FX，不靠学生猜。
3. **过程好玩 ≠ 打乱钱包**：过程奖励优先为 **局内临时道具 / 全班演出 / 老师裁定小礼**；平台积分只认最终停格。若未来要把某过程奖入账，必须走新规则快照 + 服务端事件，禁止浏览器自报金额。
4. **老师是导演，不是会计**：默认自动演出；老师可「跳过演出 / 关闭某类过程奖 / 裁定是否发放局内道具」；不得要求老师每回合点确认才能走完。
5. **投屏优先**：文案 ≥ 28px 等效、对比度高；多棋子重叠时运输镜头先收起遮挡图例；`prefers-reduced-motion` 用短淡入 + 结果字，不省略落点说明。

## 3. 路上奖励体系重设计

### 3.1 保留：最终停格平台积分

- 完整路线（含运输、飞跃、跨世界）**真实最终停稳格** → 100 / 200 / 300 / 500 / 1000。
- 仅当前行动学生；经过格、运输起点、随班迁移不另发。
- 停稳后 claim；幂等；待到账可重试；不进旧币星链路。
- **叙事定位**：这是「回家能花的钱」——家园商店闭环保留。

### 3.2 新增：过程奖励（Enrich ON-PATH，不破经济）

分三类，默认 **不进平台钱包**：

| 类型 | 含义 | 默认入账 |
|---|---|---|
| **A. 演出型** | 运输/飞跃本身就是奖：位移 + 欢呼文案 + FX | 否（目的格仍领最终积分，与现网一致） |
| **B. 局内临时道具** | 本局有效、结束清空；不写家园钱包 | 否 |
| **C. 老师裁定小礼** | 屏幕提示「老师可发一个小奖励」；老师口头/Growth/实物；系统可记勾选日志 | 否（系统不写钱包；若老师另开平台加分属平台侧，不在本方案自动做） |

**建议频次（老师主持 · 约 6–10 次回合的典型短课）**

- 演出型：地图固有（弹床/滑梯/云瀑飞跃/灯塔），碰了就播，约 0–3 次/人。
- 局内道具：全班合计约 **2–4 次/局**（由「惊喜格」+「运输落地附赠」控制，避免每格都弹）。
- 老师裁定：可选，默认关；开启后每局最多 2 次提示。

**触发格建议（新局可配置，旧局不回溯）**

| 触发 | 节点/边 | 过程内容 |
|---|---|---|
| 云朵弹床 | 停 `n06a`（及外观复用 `n34` 若启用同套文案） | 演出型 + 可选「弹射徽章」局内标记 |
| 彩虹滑梯 | 停 `n12b` | 演出型 + 可选「彩虹尾迹」本回合展示 |
| 云瀑飞跃 | 经 `e15` | 演出型（已有自动飞跃；补大字「飞跃！」） |
| 灯塔离区 | 首次到 `n18` 庆祝路径 | 演出型全班短高潮 |
| 惊喜格（新建标记） | 建议 3–5 个中性高可见格（避开冷落点与高价 1000 格抢戏） | 抽 1 个局内道具（见下表） |

> 惊喜格 **不替代** 该格最终家园积分：先播过程奖，停稳后仍按格价 claim 一次。

### 3.3 建议表：奖励名 / 玩家感知 / 老师操作 / 视觉特效 / 是否入账

| 奖励名 | 玩家感知（投屏文案） | 老师操作 | 视觉特效 | 是否入账平台钱包 |
|---|---|---|---|---|

| （保留）家园积分 | 「+200 已到账」等 | 不可关到账规则；可看待到账 | 现有到账 HUD | **是** · 仅最终停格 |

**明确不做（本 v1）**

- 不恢复旧金币/星星/骰面附加奖进钱包。
- 不让过程奖励浏览器直报金额进家园。
- 不在落点后再开录音评分题（保持主循环）。

## 4. 设施可读性：云朵弹床与彩虹滑梯（及石块底座）

### 4.1 云朵弹床（`n06a` → `n09`；外观可复用于 `n34`→`n37`）

| 项 | 规格 |
|---|---|
| **功能一句话** | 停在弹床上，弹到前方格子。 |
| **课堂话术** | EN: “Land on the cloud — bounce forward!” / 中: 「停在云上，弹到前面！」 |
| **触发条件** | 仅本回合完整骰程**最终停在**源格；路过不触发；不耗额外骰点。 |
| **运动轨迹** | 五阶段：`source` 踩弹面挤压 → `mid` 升空沿虚线运输走廊 → `exit` 开始下落 → `landed` 目的格光环 → 文案气泡 1.8–2.2s。权威落点仍由服务端运输结果决定；动画取消/404 必须收敛到权威格。 |
| **特效** | 弹面 morph（已有形态键可映射到插画形变或 CSS scaleY）；白色云屑 8–12 粒；目的格薄荷绿脉冲环 2 圈；可选轻相机 punch（低动态关闭）。 |
| **失败态** | PNG 404 → 低矮云垫回退 + 同文案；动画异常 → 瞬移到权威落点并显示「弹到这里！」；低动态 → 淡入落点 + 文案，跳过抛物线。 |
| **文案气泡** | 主：「☁️ 弹！飞到前面！」副：「目的地已亮起」；到账若发生在目的格，气泡结束后再播积分 HUD（顺序：运输演出 → 停稳 → claim）。 |
| **静止态可读** | 弹面上方常驻小箭头↗或脚印图标；节点旁微型标签「弹床」；hover/老师预览可显示「停稳 → 弹到 n09」。 |

### 4.2 彩虹滑梯（`n12b` → `n14`）

| 项 | 规格 |
|---|---|
| **功能一句话** | 停在滑梯顶，滑到前方格子。 |
| **课堂话术** | “Slide down the rainbow!” / 「停在滑梯，滑到前面！」 |
| **触发条件** | 仅最终停 `n12b`；若骰程在 `n12b` 后还有步，走普通边 `e12b→n13b`，**不中途滑**。 |
| **运动轨迹** | `source` 坐上滑口 → 沿插画不透明表面取样曲线下滑 → `landed` 在 `n14`；不遮挡 `n13b` 中心 R24。 |
| **特效** | 彩虹拖尾；落地小星爆；可选「谁滑得最远」仅文案娱乐（无数值竞争）。 |
| **失败态** | 同弹床：回退曲线 + 权威落点 + 文案「滑到这里！」。 |
| **文案气泡** | 「🌈 滑滑梯——到啦！」 |
| **静止态可读** | 滑口处小「下滑」三角；标签「滑梯」；预览「停稳 → 滑到 n14」。 |

### 4.3 底座 / 「怪石块」改造

| 项 | 建议 |
|---|---|
| **改成什么** | 弹床：改成 **浅草甸土丘 + 一圈云絮围边**（或贝壳纹木环），禁止孤立灰色立方石块。滑梯：滑道落在 **柔和土坡/云阶** 上，支架用同色木材或藤蔓，不出现工业金属与未知岩石。 |
| **为什么** | 晶港画风是梦幻草地、云海、贝壳屋、风车（`CRYSTAL_HARBOR_SCENE_V1`）；硬石块像未完成占位，破坏「游乐场」可读性，也是用户点名的违和点。 |
| **与地图统一** | 色相贴近 zone 薄荷/暖黄石板；阴影软、边缘圆；高度低于角色 pawn，避免挡路标；前缘裁切多边形继续遮挡角色脚部以保持 2.5D 层叠。 |
| **实现策略** | P0 优先改插画 PNG/锚点（展示层），**不改** Board 坐标与运输规则；回退图形同步改成「云垫/土丘」矢量，禁止回退回机械炮台。 |

## 5. 全图体验节奏（开局 → 中盘 → 终局）

目标：一节课像「短游乐场探险」，而不是「安静领工资」。

| 阶段 | 时机 | 高潮设计 | 老师感知 |
|---|---|---|---|
| **开局点燃** | 选角后第一人第一次掷骰前 | 3 秒晶港标题卡：「云港星星大冒险」+「停在云上会弹出去哦」；地图轻扫过弹床/滑梯各一次（可跳过） | 一句预告，建立期待 |
| **前段熟悉** | 第 1–3 次行动 | 以普通行走 + 首次碰到设施为高潮；第一次弹床/滑梯用完整五阶段 + 稍长气泡 | 教规则的最佳窗口 |
| **中盘起伏** | 第 4–7 次行动 | 惊喜格局内道具（若开启）；云瀑飞跃补文案；分岔选择时镜头对准两条路 | 节奏不靠加钱，靠变化 |
| **后段冲刺** | 接近灯塔/跨区 | `n18` 灯塔首次全班演出；高价格（500/1000）停稳时积分 HUD 加强（字号/彩带），仍只一笔 | 终点感来自「亮灯+大额到账」 |
| **收束** | 老师结束本局 | 结果页：每人家园本局到账合计 +「本局最弹/最滑」趣味统计（可选，纯展示） | 不发额外整局钱包奖（契约） |

**节奏约束**

- 单次运输演出建议墙钟 ≤ 3.5s（低动态 ≤ 1.2s）。
- 全班击掌类全屏演出每局 ≤ 2 次。
- 任何过程层失败不得阻塞下一枚合法骰子的发放资格（待到账规则仍约束积分 claim）。

## 6. 老师侧控制（可开关 / 可裁定）

课前或局内「导演面板」（默认折叠，避免误触）：

| 控制项 | 默认 | 说明 |
|---|---|---|
| 运输设施演出 | 开 | 关则瞬移到权威落点仍显示一句结果文案 |

| 开局地图预告扫视 | 开 | 可跳过 |

| 全班击掌提示 | 关 | 老师手动点播放 |
| 老师小贴纸裁定提示 | 关 | 仅提示，不写钱包 |
| 积分到账 HUD | 开 | 不可关闭到账规则本身 |
| 低动态强制 | 跟随系统；老师可「本局强制简化动画」 | 课堂投影卡顿时用 |

**裁定原则**：自动能走完回合；老师只在「发贴纸 / 击掌 / 跳过演出」时点击；不引入「每步确认」。

## 7. 分阶段落地（给 Codex 的 P0 / P1 / P2）

### P0 · 清晰可读（建议第一刀）

**做**

1. 弹床/滑梯静止态：标签 + 方向暗示（箭头/下滑三角）。
2. 触发文案气泡固定文案（中英可配置，先中文投屏大字）。
3. 五阶段演出与现有 `source/mid/exit/landed` 对齐；低动态/404/取消收敛。
4. 底座重绘：云絮土丘 / 云阶，去掉怪石块；回退矢量同步。
5. 云瀑飞跃、灯塔补一句大字（若缺失）。
6. 老师开关：运输演出、教学标签、开局预告、强制简化动画。

**不做**：局内道具、再动一格、钱包新事件。

**验收**

- 1920×1080：未玩过的人指出弹床/滑梯功能正确率（内部走查）≥ 目标「一眼能懂」。
