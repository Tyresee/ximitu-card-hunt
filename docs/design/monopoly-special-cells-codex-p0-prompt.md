## 已拍板（写进实现）

1. 全班前进 **包括触发者本人**（「全班」最好懂；触发者已领本格积分，被推后不再领）。
2. **保留「全班小红包」**：触发者照常领本格积分；另为在场每位学生（含触发者）各 +50。这是对「只有当前行动学生入账」的唯一例外。
3. 积分类特效格（闪亮星 ×1.5 / 幸运袋 +100 / 双星 ×2 / 金皇冠 ×3 / 全班小红包）**全部一次性**：被最终停稳触发一次后即熄灭成普通格（快照 `consumed[]` 记录，刷新不复活）。移动类中全班前进 1·2 与再掷一次整节课常驻，仅全班前进 3 一次性。
4. **开场顺序**：老师选完名单、进入地图时，**先亮出「本节课宝藏」阵容，再把宝藏炫酷地撒到地图上**（见下「开场掉落分镜」）。

事件卡方案（classroom-events v1/v2）**不实现**；本任务只做特效格。

## 一句话玩法

每节课开局，棋盘上随机掉落一批特效格。停倍率格 → 本格积分翻倍或加额；停全班格 → 老师口述任意小挑战 → 点「完成」后全班前进 N 格。

## 9 种类型

积分类：闪亮星 ×1.5；幸运袋 +100；双星 ×2；金皇冠 ×3（稀有、一次性）；全班小红包（每人 +50）。
移动类：全班前进 1 / 2 / 3（前进 3 稀有、一次性）；再掷一次。
明确不做：惩罚格、传送门、×1.2、任何教法任务模板（全班格只显示「老师有一个小挑战！」）。

## 掉落规则（服务端权威）

- 数量（默认「中」）：1–2 人 12；3–5 人 10；6–8 人 8。老师可开局选少/中/多。
- 权重与上限：闪亮星 25%；全班前进 1 18%；幸运袋 15%；双星 15%（≤3）；全班前进 2 8%（≤2）；小红包 8%（≤1）；再掷 5%（≤2）；金皇冠 4%（≤1）；全班前进 3 2%（≤1）。移动类合计 ≤4。超上限则在剩余类型按权重重抽。
- 禁放：起点及后 3 格；运输源 n06a、n12b；冷落点 n09、n14；灯塔 n18；分岔决策格；其它设施格。运输落点永不叠特效。
- 间距 ≥4 格；≥4 个特效时按世界比例分散，晶港四区每区至少 1。
- 金皇冠只放 100/200/300 格；全班前进 3 不放两世界最后 10 格。
- `layoutSeed = hash(sessionId, drawNumber)`；布局写入规则快照；第一次掷骰前可无限「重新掉落」；掷骰后锁定。浏览器不参与抽取。

## 结算

- 只认完整路线真实最终停稳格；路过不算。`金额 = round10(基础档 × 倍率)` 或 `基础档 + 100`；单笔上限 3000；一格一种效果。
- claim 服务端用快照算金额；浏览器不传金额；沿用现有幂等键。
- 小红包：本格 claim + 在场每人一笔 +50，幂等键 `instanceId+studentId`。
- 全班移动：领完本格积分后弹窗；完成/取消；被推格不 claim、不触发特效或运输；默认主路线；每课成功 ≤3；`group-move/:instanceId/resolve` 幂等。
- 再掷：本格 claim 后额外一次合法骰；第二次停「再掷」不再追加。

## 新规则版本

`RewardPolicy = points-only-v2-special-cells`。仅新局启用；旧局快照不迁移。不改 Board 坐标、运输目标、骰面、最终停格档位契约。

## 开场掉落分镜（设计稿 §5.1）

选完名单 → 点「进入地图」→ 等服务端 `draw` 返回 → 开播。动画只演出，**从不决定位置**。完整版 6–9s，可随时跳过。

| 拍 | 时间（10 格示例） | 内容 |
|---|---|---|
| 0 转场 | 0–0.8s | 名单淡出；镜头拉远成晶港全图俯瞰（只用现有美术）；地图压暗约 55% |
| 1 宝藏亮相 | 0.8–3.8s | 中央星门宝箱（贝壳木 + 云絮）开盖出光柱；大字「本节课宝藏」；卡片按类型分组逐张翻面（普通 → 少见 → 稀有），右上角数量徽章「×3」；金皇冠 / 全班前进 3 额外 0.6s 金闪 +「稀有！」 |
| 2 流星撒格 | 3.8–7.3s | 卡片化作对应颜色的发光流星，沿弧线飞到快照里的格子；落地 2 圈光环 + 火花 + 图标回弹；稀有最后落，慢动作 1.0s，金色大光环 + 4px/150ms 轻震 |
| 3 收束 | 7.3–8.4s | 地图恢复亮度；阵容缩到右上角变成可折叠图例；大字「准备开始！」；掷骰按钮亮起 |

- 压缩：`flip = clamp(1.5s/组数, 0.18, 0.3)`，`stagger = clamp(2.4s/格数, 0.08, 0.2)`；普通飞行 0.7s，稀有 1.0s；16 格也必须 ≤ 9s。
- 跳过：点任意处 / 空格 / 「跳过 ⏭」→ 1 帧内显示最终布局。
- 重新掉落：先请求 `draw`（`drawNumber+1`），再播 3s 短版（旧图标碎成星屑 0.3s → 阵容一次弹出 0.8s → 撒格 1.5s，不慢动作、不震动 → 收束 0.4s）。
- 低动态（`prefers-reduced-motion` / 简化动画）：无镜头、流星、粒子、震动；阵容淡入 → 图标同时淡入 → 「准备开始！」，≤ 1.5s，信息完整。
- 刷新或重连：直接显示最终布局，不重播（本地 `introSeen[sessionId:drawNumber]`）。演出未结束不能掷骰。
- `draw` 慢：显示「宝藏准备中…」，最多 3s；失败显示「再试一次」，**禁止前端编造布局**。
- 声音（走现有音效通道 + 静音开关，没有资源就静默）：转场风声、开箱叮、翻卡嗒（音高递增）、稀有锵、流星咻 + 落地叮、收束和弦。
- 投屏：标题 ≥ 64px，卡片 ≥ 160×200，徽章 ≥ 36px，「准备开始！」≥ 72px；阵容不压格标签。

**实现提示**：独立模块 `SpecialCellsIntroSequencer`（输入：快照布局 + Board 给出的格子屏幕坐标；`play({mode:'full'|'short'|'reduced'})→Promise`，`skip()`）。叠加层在棋盘上、HUD 下，不插入文档流（无布局偏移）。卡片用 CSS transform/opacity，流星和粒子用一块 Canvas 2D（或项目已有动效引擎），统一一条 rAF 时间线。开播前预加载并 decode 图标；粒子 ≤ 300；目标 60fps，连续 10 帧 > 24ms 时自动减粒子、关拖尾。格上真实图标由棋盘层渲染，流星落地前 `visibility:hidden`，落地瞬间显示。顺序确定：类型组顺序 + 组内按路线序号。

## 前端最低交付

开场掉落分镜（上节；完整 6–9s 可跳过，重掉 3s 短版，低动态 ≤1.5s）+ 重新掉落 + 数量档位；格上常驻图标；落地大字算式（如 `200 × 2 = 400！`）；全班格「完成 / 取消」；角落可折叠图例。图标 ≥ 格宽 60%；文案投屏可读。

## 验收（必须全绿）

- 同一 `sessionId+drawNumber` 布局一致；重掉换布局；掷骰后不能重掉。
- 1000 次模拟：禁放、间距、分散、上限均满足。
- 停双星 200 → 钱包 +400 一笔；路过不加；刷新不双发。
- 弹床/滑梯后按冷落点原价，无倍率。
- 全班前进：取消不移；确认只推一次；被推不入账不连锁；第 4 次「今天走够啦」。
- 关倍率类后布局无类型 1–5。
- 开场：转场 → 阵容（分组翻牌 + 徽章 + 稀有金闪）→ 流星撒格（稀有最后）→「准备开始！」；10 格 6–9s，16 格 ≤ 9s。
- 阵容类型 / 数量与每颗流星落点均等于服务端快照。
- 跳过 1 帧内出最终布局；中途刷新不重播、不重抽；低动态 ≤1.5s 且信息完整。
- 重掉短版 ≈ 3s；掷骰后重掉按钮消失；`draw` 失败不出现前端编造的格子。
- 1920×1080 截图后排可读；教室笔记本演出期间平均 ≥ 55fps，CLS = 0。
- 旧局行为不变；`npm run verify` 全绿。
