## 边界

- 开局下拉区按所选模式显示：老师主持只保留“课堂模式”和“棋盘主题”，不显示或占位
  “教学内容”“发言保障”，隐藏控件同时禁用；学生和角色选择保留。切回知识答题时
  恢复这两个字段及原有选择。老师模式的预览不读取题库或计算朗读次数。
- 老师模式的运行时不绑定 LearningPack、task 或评分策略；不请求录音/ASR/AI评分。
- 使用独立机会命令和状态，不伪造 accepted、100 分、知识点正确或教师补评分。
- 共享原有路线规划、岔路、跨世界、逐格移动、最终落点、金币与星星结算。
- 老师机会和已抽取的骰面在动画前保存；多点、刷新、重复结算不能重复发放。
- 同局金币/星星持续累计；老师手动结束整局后封存，新开一局归零；不对接 Growth。
- 知识答题模式维持原语音最高优先级锁、分档与公平轮换，不允许借本模式绕过该锁。
- 当前课堂棋局和机会持久化沿用此浏览器本地快照，不宣称跨设备同步或服务端骰子权威。
  学生稳定身份与每局资产仍走原认证、版本校验、服务端复算、幂等与待同步队列。
