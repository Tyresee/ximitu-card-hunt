- 骰子仅决定移动步数，不再附带金币、星星、卡片、钥匙或精灵奖励。原六面随机概率、评分选骰档位和已锁定骰点不变。

- 正常掷骰只给当前行动学生发放完整路线的真实最终格；停稳后进入家园共享钱包。2026-10-31 用户明确新增例外：完成全班前进挑战后，每位实际移动学生（含触发者）领取自己新落格的原格价，不触发新 bonus 或运输连锁。普通经过、运输起点、旧远征随班迁移、结束本局均无额外积分。

- 默认老师主持自由记分的新局启用；未登记旧局和知识答题不自行获得平台积分资格。
