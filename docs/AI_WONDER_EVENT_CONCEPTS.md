## 1. 核心判断

不把 Mario Party 的“每轮结束进入小游戏”照搬进课堂。

本游戏自己的标志性机制应当是：

```text
孩子说出的完整句子
→ 变成可见的“句子种子”
→ 在不可预知但可控的时刻打开 AI 奇遇门
→ 屏幕里的问题跑进真实教室
→ 每个孩子完成一个实体动作和一句个人输出
→ 共同创造的角色、地点或故事永久进入本局棋盘
```

它带来的惊喜不是“突然换了一道题”，而是：

- 刚才说过的句子真的改变了世界。
- 网页和教室里的画纸、卡片、铃铛、白板发生联动。
- 结果不是短暂得分，而是全班留下一个看得见的共同作品。
- AI 负责剧情、角色声音、理解作品和异步纪念图，不掌握课堂裁决权。

## 2. 已确认可使用的实体资源

当前优先使用教师已经确认拥有的材料：

| 类型 | 已有材料 |
|---|---|
| 绘画与展示 | 铅笔、蜡笔、画笔、白板、A4 纸 |
| 卡片与抽取 | 闪卡、魔术口袋、可夹卡片的头箍 |
| 互动 | 六面可插闪卡骰子、旋转指针、小苍蝇拍、小铃铛 |
| 拼读 | 磁吸字母 |
| 制作 | 彩色打印机 |
| Family 专用 | 人物头像、特征、服饰、小动物、学校用品、玩具拼搭卡 |

没有确认的材料不能写成首期必需品，包括剪刀、胶水、胶带、颜料、
彩纸、积木、塑封机和多套同类教具。

## 3. 统一触发系统

### 3.1 句子种子

每个已触发骰子的完整句，可由已有教学判定结果安全提取：

```json
{
  "speakerId": "child-04",
  "subject": "she",
  "beForm": null,
  "haveForm": "has",
  "quantity": 2,
  "noun": "apple",
  "countability": "countable",
  "familyRole": "sister",
  "relation": null,
  "sourceTaskId": "task-018"
}
```

大模型不能重写这份学习证据，也不能因为奇遇剧情把错误答案记成正确。

### 3.2 意外感与课堂可控性

- 每局开始时由服务端提交一个隐藏阈值，例如 4–6 枚句子种子。
- 达到阈值后，只有奇遇格、稀有宝箱或教师放行才能真正打开。
- 单个 12 分钟游戏段最多出现 1–2 次。
- 同一个事件包有 `20 秒 / 45 秒 / 90 秒` 三档。
- 教师在课前勾选“今天已经准备好的材料”，事件导演只从可用模板抽取。
- 若课堂时间不足，能量保留为下一次地图奖励，不强制打断当前回合。

### 3.3 共同结果

奇遇结束后只产生以下结果：

- 打开全班共享捷径。
- 点亮一个地图地标。
- 增加一名原创访客。
- 把儿童作品挂进家庭画廊。
- 给共同 Family Tree 增加树枝、叶子或灯笼。
- 获得一张全班收藏卡。

不产生个人英语排名，不偷取其他队伍资源，不淘汰孩子。

## 4. 六个事件包

### A. AI 捣蛋精 · 全班修复现实

**定位：推荐首发，通用性最强。**

地图中的原创捣蛋精把最近一句话或画面改坏：

- `She has two apples.` 变成画面上只有一个苹果。
- `He is my brother.` 中人物被换成女孩。
- `They have some rice.` 中 `have` 被换成 `has`。

课堂角色：

1. 侦察员按铃指出世界发生故障。
2. 捕捉员用苍蝇拍找到正确人物或物品闪卡。
3. 修理员在白板上放回卡片或磁吸字母。
4. 发言员说出完整修复句。
5. 确认员按教师指定方式检查实体结果。

AI 负责：

- 从最近句子种子选择一个可用场景。
- 用白名单中的错误变换生成受控事件 JSON。
- 用 CosyVoice 播放捣蛋精的搞笑台词和正确模型句。

AI 不负责：

- 自由创造语法错误。
- 判定骰子、奖励、掌握或输赢。

优点：

- He/She、be、have/has、单复数、可数性和 Family 都能覆盖。
- 几乎所有现有教具都能参与。
- 断网时仍可用预置错误卡和缓存音频完成。

主要风险：

- 错误示范停留过久会干扰学习。错误画面必须有明确“故障”视觉，
  并在 2–3 秒内出现正确模型句。

### B. 一句话一笔 · 会长大的家庭画廊

**定位：最能形成产品记忆点的艺术奇遇。**

流程：

1. 屏幕为每个孩子分配一个人物、物品、数量或关系。
2. 大家在一张或两张 A4 纸上作画，也可使用现有 Family 拼搭卡。
3. 每人完成自己的部分后，按顺序说一句描述。
4. 教师只拍作品，不拍孩子正脸。
5. 千问视觉返回“可能看见了什么”的结构化候选，教师确认或修正。
6. 原画立即以纸张动画进入棋盘。
7. 万相在后台把作品变成奇遇明信片或下节课封面。

示例：

```text
Draw a family picnic.
Child A: This is my sister.
Child B: She has two apples.
Child C: He has some rice.
Child D: They are happy.
```

优点：

- 孩子的作品会留在世界里，比一次积分更有归属感。
- 可自然兼容全部目标知识点。
- 与教师已有画材、打印机和拼搭卡高度匹配。

主要风险：

- 视觉理解可能看不懂抽象儿童画，因此只能提议，必须由教师确认。
- 图片生成不可进入课堂关键路径；失败时直接展示原画。

### C. 会说话的 Family Tree

**定位：Family 单元终章与 Boss 奇遇。**

流程：

1. AI 树精用角色声音说出一条受控线索。
2. 孩子轮流摆放或补画一位家庭成员。
3. 其他孩子添加服饰、物品、数量或食物。
4. 每人用一个当前目标句介绍自己的贡献。
5. 每完成一层，屏幕家庭树长出树枝、叶子、灯笼或树屋。

推荐句型层级：

```text
This is my mum.
She is happy.
She has a hat.
They have two apples.
They have some rice.
```

首期不临时引入多跳亲属推理或超纲所有格。

### D. 神秘口袋奇遇快递

**定位：短时、稳定、无需摄像头。**

1. CosyVoice 广播一张由句子种子组成的“奇遇快递单”。
2. 一人从魔术口袋抽人物卡。
3. 一人戴头箍成为隐藏身份。
4. 一人用旋转指针决定数量、物品或句型。
5. 发言员说完整句，包裹飞入地图房屋并铺出一段新路。

适合 `20 秒` 或 `45 秒` 模式。

### E. 句子维修站

**定位：白板与磁吸字母的语法协作。**

AI 角色让地图桥梁出现 2–4 个“缺失零件”。孩子使用人物卡、物品卡、
磁吸字母或白板修好 `he/she`、`is/are`、`have/has`、数量与名词，
最后由指定发言员读完整句，桥梁恢复。

它与 A 的区别是：A 强调剧情故障与多种教具角色；E 是更短、更专注的
语法维修模板。

### F. 角色来电 · 故事接龙

**定位：后续 Power Up 角色素材接入后的剧情型事件。**

1. 原创占位角色或已授权教材角色突然来电求救。
2. 每个孩子贡献一句人物、关系、物品或数量信息。
3. 千问把已经通过安全校验的句子整理成 30–60 秒短故事。
4. CosyVoice 用角色化但非仿冒的音色朗读。
5. 后台生成一张故事封面，下一节课再次出现。

故事只能使用已发布人物、词汇和句型白名单。

## 6. 推荐发布顺序

### 首发组合

1. **通用稀有事件：A AI 捣蛋精。**
2. **稳定短事件：D 奇遇快递。**
3. **课程终章：C 会说话的 Family Tree。**

这三种都能完全使用本地模板和现有教具运行，阿里云失败不会卡住课堂。

### 第二阶段

加入 B 家庭画廊：

- 视觉理解只做候选提取。
- 教师确认后写入作品元数据。
- 万相异步生成纪念图。
- 下一回合或下一节课展示，不让孩子等待。

### 第三阶段

教材人物正式授权并导入后，加入 F 角色来电和更多故事包。

## 7. 1–8 人角色分配

| 人数 | 分配方式 |
|---:|---|
| 1 | 孩子与 AI 伙伴依次完成找卡、摆放、作画和发言 |
| 2 | 实体操作员＋发言员，下次交换 |
| 3–4 | 一人一职：侦察、寻找、修理、发言 |
| 5–6 | 两队共享一个事件，每队修一部分；每个孩子仍有个人角色 |
| 7–8 | 最多四队；画手、抽卡员、维修员、发言员、确认员等轮换 |

多人讨论、绘画和实体操作期间关闭 ASR。只有轮到指定发言员时才打开
麦克风，避免把全班声音当成一个答案。

## 9. 课堂运行架构

```text
已发布关卡与词汇白名单
        ↓
ASR final → 规则判定 → 骰子事务
                 ↓
             句子种子仓
                 ↓
隐藏阈值＋奇遇格＋冷却时间＋教师材料开关
                 ↓
      预审事件模板选择器
                 ↓
Qwen 结构化台词/角色 → Schema 校验 → 内容安全
                 ↓
CosyVoice / 本地动画 / 实体教具流程
                 ↓
教师确认 → 共同地图变化 → 返回棋盘
                 ↓
可选：作品照片 → 视觉候选 → 教师确认
                 ↓
可选：Wan 异步纪念图 → 下一回合或下节课展示
```

任何 AI 调用都不能持有骰子事务锁，也不能阻塞下一回合。

## 10. 延迟与降级

以下是产品目标，不是云服务 SLA：

| 环节 | 目标 | 超时或失败 |
|---|---:|---|
| ASR 句末 | 1.2 秒内 | 2.5 秒后教师确认/重听 |
| 规则判断 | 300ms 内 | 不确定时才调用结构化模型 |
| TTS 首包 | 800ms 内 | 缓存台词或本地提示音 |
| 作品理解 | 4 秒内 | 教师直接确认作品元素 |
| 图片生成 | 不阻塞 | 原画先进入棋盘，结果以后出现 |

断网时使用：

- 已发布事件 JSON。
- 本地缓存角色台词。
- 教师确认按钮。
- 原画或预制贴纸动画。

## 11. 儿童隐私

- 默认只拍画纸、卡片和教具，不拍孩子正脸。
- 摄像头由教师主动开启，并保持明显状态提示。
- 原始录音默认仅流式处理，不长期保存。
- 儿童使用匿名座位 ID，不把真实姓名发给模型。
- 作品图片使用短生命周期存储。
- API Key 只放后端，不能进入浏览器代码。
- AI 视觉结果必须显示为“候选识别”，教师确认后才写入作品记录。

## 12. Codex 可生成的结构化事件

Codex 根据教师的自然语言要求生成事件 JSON，但只能选择已经登记的
能力、材料和动作，不能写任意 JavaScript。

```json
{
  "schemaVersion": "1.0",
  "eventId": "wonder-repair-have-has-01",
  "title": "苹果数量故障",
  "templateId": "reality_repair",
  "lessonTags": ["he_she", "have_has", "countable_plural"],
  "eligibleSeeds": {
    "requiresHaveForm": true,
    "requiresQuantity": true
  },
  "trigger": {
    "seedThreshold": [4, 6],
    "eligibleSpaceTypes": ["wonder", "rare_chest"],
    "cooldownTurns": 4,
    "maxPerSegment": 1
  },
  "durationOptionsSec": [20, 45, 90],
  "materials": {
    "required": ["flashcards", "bell"],
    "optional": ["fly_swatter", "whiteboard", "magnetic_letters"]
  },
  "roles": ["scout", "catcher", "repairer", "speaker"],
  "beats": [
    "npc_announces_fault",
    "bell_signal",
    "find_correct_card",
    "repair_sentence",
    "designated_speaker_answer",
    "world_repairs"
  ],
  "languageOutput": {
    "oneSpeakerAtATime": true,
    "mustUsePublishedSentenceFrame": true
  },
  "worldMutation": {
    "type": "unlock_shared_bridge",
    "targetId": "garden_bridge"
  },
  "fallback": {
    "scriptAssetId": "repair-default-01",
    "voiceAssetId": "repair-default-voice-01"
  }
}
```

发布前必须经过 JSON Schema、教材词汇白名单、材料存在性、时长、多人公平、
内容安全和断网降级校验。

## 13. 首期验收标准

1. 奇遇不固定在每轮结束发生。
2. 奇遇内容至少引用一枚本局真实句子种子。
3. 每个孩子至少获得一个实体角色和一次个人输出机会。
4. 不要求多人同时对麦克风喊答案。
5. 奇遇结果永久改变本局地图或共同收藏。
6. AI 失败时，教师能在 2 秒内切到预制脚本继续。
7. 视觉模型不评价儿童画，也不独立决定正确、奖励或掌握。
8. 图片生成不阻塞棋盘和下一题。
9. 任何奇遇都不改变骰子概率或学习证据。
10. 1–8 人均能用同一模板扩缩，不增加超过四枚队伍棋子。
