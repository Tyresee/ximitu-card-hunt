# 声控奇遇棋 · 2D 派对棋玩法适配说明

> **更正说明（2026-07-27）**：本文的家庭小镇与 Family Tree 只作为一个
> 可选 ThemePack / LearningPack 示例，不再作为固定游戏框架。通用棋盘、
> 内容包和活动模板的工程契约以
> [通用声控派对棋引擎](./UNIVERSAL_VOICE_BOARD_ENGINE.md) 为准。

- 状态：设计提案 v0.1
- 日期：2026-07-27
- 目标：借鉴主机派对棋的玩法节奏，形成原创、可教学、可稳定开发的 2D 网页游戏
- 参考图片：教师提供的 Nintendo Switch Mario Party 对局截图
- 关联基线：[声控奇遇棋 PRD](./VOICE_ADVENTURE_BOARD_PRD.md)

## 1. 官方规则研究结论

Nintendo 官方页面反复出现的核心循环是：

1. 玩家依次掷骰并沿棋盘移动。
2. 落点触发奖励、阻碍或特殊事件。
3. 所有玩家完成一轮后进入多人小游戏。
4. 小游戏产生金币等途中资源。
5. 资源用于购买道具或兑换最终目标。
6. 对局按预设轮数结束，再比较最终目标数量。

官方资料：

- [Super Mario Party Jamboree · How to play](https://www.nintendo.com/us/store/products/super-mario-party-jamboree-switch/)
- [Mario Party Superstars · Nintendo UK](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Mario-Party-Superstars-1987416.html)
- [Super Mario Party modes tips](https://play.nintendo.com/news-tips/tips-tricks/super-mario-party-modes-tips-tricks/)

声控奇遇棋只借鉴这套节奏关系，不复制 Nintendo 的角色、地图、美术、
格子图标、字体、音乐、Dice Block 造型或 HUD 排列。

## 2. 原创课堂版本的一局循环

```text
当前儿童看到语音任务
→ 说一个完整目标句
→ 主目标通过或完整句命中本题受控触发词
→ 服务端立即决定 1–6 点骰值、路径和落点事件
→ 2D 骰子在当前棋子头顶自动出现
→ 前方路径逐格点亮，棋子逐格移动
→ 结算金币、宝箱、传送或派对站
→ 下一位儿童
→ 每个完整句贡献一枚结构化“句子种子”
→ 达到隐藏阈值并遇到奇遇格/稀有宝箱时，随机打开 AI 奇遇门
→ 屏幕任务进入真实教室，全员在 45–90 秒内协作完成
→ 共同作品或修复结果永久改变本局棋盘
→ 继续下一轮
→ 教学覆盖达标且精准挑战已呈现后进入 Family Tree Boss
```

儿童全程不说第二条投骰口令，也没有可点击的投骰按钮。

## 3. 四条互不混淆的结果轨道

| 轨道 | 可见范围 | 作用 |
|---|---|---|
| 欢乐金币 | 队伍和全班 | 获取道具、兑换派对徽章 |
| 派对徽章 | 队伍和全班 | 本局的趣味冒险结果 |
| 共同知识星星 | 全班共享 | 每次完成一张任务固定 `+1` |
| 学习证据 | 仅教师 | 主目标、提示、修复和迁移表现 |

孩子赢得更多派对徽章不表示英语能力更强。语法证据不进入公开排名。

## 4. 2D 家庭冒险小镇

首张地图建议：

- 约 28 个固定节点。
- 2 个明显分岔。
- 1 个可回到主路的小环线。
- 1 组固定传送门。
- 家庭住宅、社区花园、小镇市场、湖边野餐地、树屋和家庭派对站。
- Family Tree Boss 入口由教学覆盖条件解锁，不要求随机踩中。

## 5. 首期格子

格子同时使用颜色、图标和外轮廓，不只依赖颜色。

| 格子 | 作用 |
|---|---|
| 句型格 | 普通完整句任务 |
| 阳光金币格 | 获得少量欢乐金币 |
| 小宝箱格 | 获得收藏或一个受控道具 |
| 固定传送门 | 移动到配置好的安全节点 |
| AI 奇遇格 | 为奇遇门充能，或在达到条件后打开一个预审事件 |
| 协作格 | 下一题邀请队友参与，但仍分别记录证据 |
| 派对站 | 金币足够时自动兑换派对徽章 |
| Boss 入口 | 教学覆盖达标后进入 Family Tree Boss |

不采用偷币、偷徽章、抢走共同星星、淘汰或公开惩罚。

## 6. 首期道具

每队最多两个道具槽；技能只能影响冒险轨道。

- **弹跳鞋**：下一次正常骰子结算后额外前进 2 格。
- **双倍宝箱券**：下次宝箱多获得一件冒险收藏。
- **追风气球**：温和落后的队伍获得一次移动加速。

道具不能修改语法判定、任务难度、骰子基础概率、发言顺序或学习证据。

## 7. 原创 AI 奇遇门

不采用“每轮结束固定进入全员小游戏”的节奏。完整句会贡献结构化的
`句子种子`，字段限制为人物、代词、be、have/has、数量、名词、
可数性、家庭身份和关系。每局在开始时提交一个 4–6 枚种子的隐藏阈值；
达到阈值后，只有踩中奇遇格、打开稀有宝箱或教师主动放行时才会触发。
每 12 分钟最多 1–2 次，并提供 `20 秒 / 45 秒 / 90 秒` 课堂时长档。

### v1：AI 捣蛋精 · 全班修复现实

1. 原创捣蛋精把孩子刚才说过的一条句子“改坏”，例如把 `She` 换成
   `He`、把 `has` 偷换成 `have`、把两个苹果变成一个。
2. 侦察员按铃发现故障。
3. 捕捉员用苍蝇拍找到正确闪卡。
4. 修理员在白板上恢复人物、物品或磁吸字母。
5. 发言员说出完整修复句，屏幕世界复原并打开一条共同捷径。

错误变换来自课程白名单规则，不由大模型自由编造；AI 只负责搞笑剧情、
角色台词和声效包装。1 人可依次承担全部角色，2–8 人按角色轮换。

### 艺术奇遇：一句话一笔 · 会长大的家庭画廊

1. 每个孩子获得一个人物、物品、数量或家庭关系角色。
2. 大家在 A4 纸上共同绘画，或使用现有 Family 人物/服饰/物品拼搭卡。
3. 每人按顺序说一句描述自己的部分。
4. 教师只拍画纸；视觉模型给出“我看到了什么”的候选结果，由教师确认。
5. 原画立即进入棋盘成为画廊、访客或地图装饰。
6. 万相可以在后台把作品转为奇遇明信片，完成后再出现；课堂不等待生图。

AI 不评价画得好不好，也不根据视觉识别决定胜负或学习掌握。

### 课程终章：会说话的 Family Tree

孩子摆放或补画家庭成员卡，用 `He / She`、`be`、`have / has`、
单复数、可数 / 不可数句型逐层唤醒家庭树。最终结果是全班共同完成的
地图地标，而不是个人英语排行榜。

## 8. 1–8 人

- 1 人：孩子与角色伙伴共同挑战，不制造假对手。
- 2–4 人：个人或两队，最多 4 枚棋子。
- 5–8 人：2–4 队，每队 1 枚棋子，仍最多 4 枚棋子。
- 队伍棋子和儿童发言队列分开。
- 队内儿童严格轮换，不能由一名儿童代替整队。
- 每个大轮中，各队获得同样数量的移动机会。
- AI 奇遇不依赖某队领先；每名在场儿童至少获得一个实体角色和一次按序
  发言机会。

## 9. 网页实现边界

- 一个 SVG `viewBox` 承载地图、道路、节点和棋子。
- 普通 HTML 承载 HUD、任务卡、转写和教师控制。
- 角色使用可替换的透明 PNG/SVG 占位图。
- 骰子、路径、落点、金币、道具和传送都由服务端权威决定。
- 浏览器只播放 `dice_reveal`、`pawn_step`、`chest_open`、
  `portal_jump`、`reward_delta` 等声明式效果。
- 动画只使用 `transform`、`opacity` 和短帧序列。
- 支持减少动态；刷新或重连直接恢复服务端最终节点和待展示事件。
- 不使用 Three.js、WebGL、碰撞物理或自由摄像机。

## 10. 分期

### v1 必须

- 原创全屏 2D 棋盘。
- 完整句触发自动骰子。
- 逐格移动、固定分岔、金币、宝箱、传送和派对徽章。
- 句子种子、隐藏阈值和一个可离线降级的 AI 奇遇模板。
- 现成铃铛、闪卡、苍蝇拍、白板、磁吸字母与 Family 拼搭卡的角色流程。
- 1–8 人与最多 4 枚队伍棋子。
- 服务端权威结算和断线恢复。

### 后续增加

- 移动的派对站。
- 商店和复杂库存。
- 角色伙伴与人物专属能力。
- 走到岔路时的实时选择。
- 多种 AI 奇遇事件包。
- 作品视觉理解和后台异步奇遇明信片。
- 自动镜头、昼夜与地图机关。
- 多元冒险称号。

### 持续禁止

- 复制 Nintendo 角色、地图、图标、声音和品牌视觉。
- 偷取其他儿童的金币、徽章或知识星星。
- 因 ASR 没听清或语法错误扣奖励。
- 用音量、发音分或答题质量改变骰子点数。
- 公开英语能力排行或淘汰儿童。
- 多名儿童同时向同一个麦克风喊答案。
- 课堂运行时用大模型自由决定判分、概率或事件代码。
