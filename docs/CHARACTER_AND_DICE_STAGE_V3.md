# 20 位冒险伙伴与全屏骰子舞台 v3

- 用户决定：2026-09-22。
- 范围：课前角色选择、角色美术、骰子演出和回到棋盘后的点数提示。
- 规则边界：沿用正式评分、骰面快照、合法随机、逐格移动和最终落点结算。

## 角色与兼容

可选角色由 8 个增加到 20 个，全部使用新一批圆润、柔和配色的动物伙伴美术。
一局仍支持 1–8 名学生，每名学生选择一个不重复的角色；20 是可选角色数量，
不代表增加课堂座位。占用角色显示选择者并禁选，已选角色有明确状态；键盘操作
和重新渲染后的焦点继续可用。

原有 8 个角色 ID 保持不变，只更新它们的图片引用。因此旧棋局继续按原 ID
恢复角色，不重新分配学生、不重置位置或资产。保留的 ID 为：

```text
cowboy
star-captain
cloud-wizard
lightning-ninja
rainbow-pilot
forest-scout
inventor
crystal-explorer
```

新增 12 个角色为布丁小狗、糯米仓鼠、竹竹熊猫、枫糖小熊猫、抱抱考拉、
棉花小羊、蜜糖小虎、暖暖狮子、星糖独角兽、薄荷小恐龙、月月浣熊、栗栗刺猬。
角色清单与三种显示场景的引用统一由
[`experience-core.js`](../public/prototypes/universal-board/experience-core.js) 中的
`CHARACTER_PROFILES` 管理。

该学生所选角色 ID。

## 全屏骰子演出

玩家在现有骰子入口选择后，复用同一颗六面骰子，进入覆盖视口的聚光灯舞台。
骰子在中央原地旋转并逐渐减速；双侧灯光、柔和光晕和舞台地面属于装饰层。
骰子结束朝向严格对应本次已经抽取的 `faceIndex`，不由动画重新抽样。

正常动态下的主要阶段：

| 阶段 | 时长 | 行为 |
|---|---:|---|
| 中央旋转 | 2000 ms | 原地旋转、持续减速，到达已抽取的骰面 |
| 舞台落定 | 550 ms | 显示本次点数和骰面奖励 |
| 舞台退场 | 180 ms | 舞台淡出，恢复正常棋盘 |
| 棋盘结果提示 | 2250 ms | 显示同一点数、前进格数和附加奖励，再继续正式流程 |

舞台落定与棋盘结果提示共保留 2800 ms 阅读时间，退场淡出单独计时；入场交接
仍由既有选骰演出负责。常量与纯动画函数位于
[`game-feel.js`](../public/prototypes/universal-board/game-feel.js)，舞台装饰位于
[`game-feel.css`](../public/prototypes/universal-board/game-feel.css)，编排位于
[`app.js`](../public/prototypes/universal-board/app.js) 的 `presentDiceRoll()`。

`prefers-reduced-motion` 下直接展示已抽取的骰面，跳过旋转、灯光扫动和舞台
退场动画，仍回到棋盘显示同一点数。没有 Web Animations 的旋转能力时采用静态
骰面；视觉降级不产生第二次抽样。取消或切换流程时隐藏舞台和棋盘结果提示，
取消当前骰子旋转；异步阶段通过当前选择身份检查，避免过期演出继续推动回合。

## 保持的正式契约

- 20 个角色均不影响评分、骰子档位、随机概率、地图路线或奖励。
- 语音模式继续先显示真实分数，再进入合法骰子和移动；老师主持仍使用原机会链路。
- 当前棋局继续使用锁定的骰面快照，动画只消费已有 `roll.steps`、`roll.faceIndex`
  与骰面奖励，不写入或重算已提交回合。
- 地图道路、节点、布局版本和运输规则未修改。拓扑基线为
  `a848499f0c3c90a8d6b155115ea6a496b96b7e914351fca0bfce824732a76352`。
- 已取消的停靠锚保持取消，必要岔路选择和金币兑换保持原规则。
