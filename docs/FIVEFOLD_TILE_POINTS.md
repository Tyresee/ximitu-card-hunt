# 棋格基础分调整（2026-11-03）

用户决定：所有棋格原基础分直接改为 500 / 1000 / 1500 / 2500 / 5000。
棋面只印最终数字（例如500），不印5×100。原黄/绿/蓝/橙/紫五档配色保持对应。
用户另明确确认：新开局以及进行中棋局的后续回合都生效；已到账和已锁定的待到账奖励保持原金额。

## 服务端权威

私有积分桥新增不可变 `monopoly-final-landing-v3`，123格逐节点为v2的五倍。
v1/v2原文件、原回执、钱包历史不重算、不补差。新局登记v3。浏览器仍不提交金额或节点。

现有局通过服务间签名的 `POST /landing-sessions/:id/upgrade-rule` 升级。
请求只含expectedUserId/expectedRuleVersion/targetRuleVersion；积分桥独立从已登记的原表生成新值。
原规则保留到ruleHistory，initialRuleVersion记录历史口径；v3.baseRevision记录v1或v2来源。
旧v1世界也只改金额，保留原world/board/level、路线、实例与位置，不能迁到新地图。
重复请求、丢响应、重启恢复都只升级一次，不会再次乘五。

游戏服务只在已锁骰/已规划回合、基础到账、加成到账、全班挑战与新落格到账全部结束后升级。
旧attempt重试先返回原骰，不触发升级。下一次新attempt在服务端随机前再次检查升级门禁。
服务器升级成功后，浏览器必须先强制保存新金额快照，才展示/继续下一次机会。

## 历史与特效

新turn和全班落格award冻结ruleVersion；旧事件缺该字段时读initialRuleVersion和ruleHistory。
已到账回执和重复领取返回原记录，不因为当前规则版本变化而再计分。
升级不重抽特效格、不改drawNumber/消耗/双骰持有/再掷/圈数/课堂前进上限。
现有锁布局中的basePoints是当时的布局审计元数据，新的实际结算以冻结turn.points为准。

×1.5/×2/×3在新基础分上计算；原+100、每人+50等固定加成不扩大。
新抽取布局以归一档位检查皇冠资格，相同seed的类型与位置保持相同，格价变为五倍。
v3总额上限15000，额外加成上限10000；旧规则原上限不放宽。桥按基础落格回执版本限制额外加成。
