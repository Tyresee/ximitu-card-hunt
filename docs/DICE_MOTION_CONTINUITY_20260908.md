# 骰子旋转连续性修正 · 2026-09-08

用户反馈上一版立体骰子旋转卡顿，缺少自然的非线性起止。只修表现层，保留骰子外观、六个结果面、概率、评分、奖励、地图与真实学生数据。

## 问题与修正

| 位置 | 已确认的问题 | 修正 |
| --- | --- | --- |
| 翻滚关键帧 | 七个关键帧的多段缓动导致连接处角速度不连续，尾部还反向回摆 | 使用一条连续速度曲线，40% 时刻达到速度峰值，之后持续减速；起止速度、加速度均为零 |
| 起始姿态 | 旋转从 -12°/18° 开始，与未旋转的 cube 不一致；待机 CSS 动画也可能覆盖内联姿态 | cube 从零角度开始；待机转子读取当前实际计算姿态再交接 |
| 最终姿态 | 先取消动画再设置结果姿态，交接顺序不可靠 | 先写入权威 faceIndex 对应姿态，再取消动画 |
| 边角材质 | 20 个倒角面各自使用 brightness 滤镜 | 改为等价的静态 sRGB 混色，保留明暗，不使用独立滤镜 |
| 阴影 | 阶段切换时透明度/缩放直接跳变 | 只对阴影的 transform/opacity 平滑过渡，低动态设置下取消过渡 |

采用 ui-animation 与 3d-build-pitfalls 的原则：区分轨迹不连续与掉帧；运动只用 transform，由 WAAPI 执行；不在主线程逐帧修改旋转。181 个采样点一次生成，分段之间不额外施加缓动。整段时长 2200ms，不重新抽骰、不调整移动与奖励结果。
