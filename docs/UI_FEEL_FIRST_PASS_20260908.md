## 实现

- 顶部每位学生的星星使用主视觉数字和暖金色底；金币作为次级资产并明确标注。
- 奖励沿原有结算链进入对应学生账户后，显示姓名、本次增量、入账后的总额。连续同一人的新提示替换旧提示，防止过时总额重叠。
- 骰子保留六个真实结果面，补齐十二条倒角和八个角面；动作改为抛起、翻滚、回弹、停稳，约 1.8 秒。
- 停稳姿态仍由原始 faceIndex 决定，没有新增随机抽样。移除旧的外围旋转光圈，六面参考收为可展开说明。
- 保留低动态效果降级路径和取消逻辑，不把动效当作业务结算来源。
- 未引入新运行时依赖。
